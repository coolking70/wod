# v0.10 沉钟机关

本版把战前队伍培养、共享补给与非战斗事件连接起来。规则为原创 WoD 灵感实现，不声称复刻原版。

## 规则

封库试炼第二房间进场时自动执行预设策略，发生在回合前技能之前。旧配置迁移为绕过。

|策略|候选技能|费用 / 难度|成功|
|---|---|---|---|
|绕过|无|无|无收益|
|解读封印|学者潮纹屏障、吟游诗人灵感启蒙|2 符纸 / 70|存活正式队员本房间全防御检定 +8|
|强行破拆|守卫盾击、射手穿石箭|3 箭矢作材料 / 60|存活正式队员本房间护甲 +3|

按进场存活、装备条件与实际技能均值选择执行者。失败损失最多12法力，最低为0；不额外消耗技能自身法力、不占行动。补给不足或无候选者则无法执行，不收费、不投点。成功效果房间结束清除，不复活倒下队员。

检定为 floor(mean × (0.5 + (u1 + u2) / 2)) ≥ 难度。事件使用由远征种子派生的独立随机流，不挤占战斗随机流。战报保留等级来源、候选排除原因、投点、费用、实际后果与快照；回放不修改结算。

## 表现与验证

新增三位支援角色头像和沉钟事件CG。插画是中性场景示意，实际执行者与结果由文本说明；事件回放自动暂停。战术实验新增绕过 / 解读单变量对照。

自动验证共79项（包含原有回归及新增机关检查）：配置迁移、候选筛选、费用、成功/失败、清除时机、独立随机、只读投影、方案及复盘。浏览器实测策略刷新保留、失败与成功CG。事件预设种子731：塞恩58/70失败，消耗2符纸、12法力；种子42：塞恩79/70成功。浏览器发现修改种子后出发可能沿用旧值，已在出发入口读取并校验输入框值。

## 边界与下一阶段

目前仅一个机关、三种策略；不是完整分支剧情系统。没有实时AI生成、后端存档或多人。下一阶段优先建立多种非战斗检定与跨房间后果，再扩展事件CG；避免只增加装饰或无作用的选项。
