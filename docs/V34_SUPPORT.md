# v0.34 战场支援轨迹

战场来源与实际受益者分别标识；增益和治疗连线暂停后保留，延迟增益使用虚线。每名单位显示当前快照中的生效/待生效效果组件数量，具体来源、数值及持续时间仍可点击单位查看。

战场下新增支援轨迹：上一处、下一处和本房间记录选择。使用完整行动分组，覆盖增益、治疗、生效和到期，包含敌方支援；明确列出来源、目标、实际数值和记录中的时限。到期连线为灰色虚线。减少动态效果偏好下保留静态支援线，取消对应动画冲击环。

所有数据来自既有事件和单位快照，不重新推算覆盖，不改战斗规则。效果组件计数不是技能数。没有制作新CG，本轮加强已有战场中规则关系的可读性。
