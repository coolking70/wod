# v0.36 战场工作区

本版让已有的战斗表现成为复盘入口，避免播放画面被长战报与统计挤出屏幕。未修改战斗规则、奖励或存档结构。

## 已实现

- 三个工作区：战场回放、行动证据、远征复盘；共用同一场报告与当前行动。
- 专注战场：收起顶部导航、统计与时间轴；保留房间、播放与退出开关。打开证据会自动退出专注模式。
- 关键行动播放：从完整记录选取完整行动组，保留房间、结算、倒下、召唤、事件、道具、效果激活；还选取每房每角色首次技能增益、治疗前血量不超过35%的有效治疗、致命攻击或造成目标攻击前至少35%血量的伤害。
- 明示精选与完整记录数量；选择被省略的记录会恢复完整播放。完整战报仍可导出。
- 突出当前行动：淡化其他角色，保留来源、受益者和效果连线。
- 战场行动摘要可进入检定与效果来源证据，原有施放跳转和返回继续工作。

精选是展示规则，不等同于自动判断胜败原因；首个增益展示也不表示其他施放没有作用。历史重演仍使用当前规则，未增加历史事件归档承诺。本版复用已有插画与效果，没有生成新CG。

## 验证

- 全量自动测试：201/201 通过（node --test tests/*.test.mjs）。
- 自动测试包含完整行动保留、输入不变、同房重复增益过滤、跨房重置、伤害筛选、急救阈值边界和零治疗排除。
- 浏览器：工作区切换、专注模式与退出、自动播放推进、跨房间停止旧播放、关键/完整切换、到期记录定位、支援来源往返。
- 测试公会第7次远征载入后修改专修，在出征核对看到变化；第8次远征3/3房间、6人生还，领取150金币与每人70经验，战利品与历史快照保留，历史重演可用。
- 第8次远征第一房精选18/68个行动与状态。该数字取决于队伍、种子和战报，不是固定关卡参数。
