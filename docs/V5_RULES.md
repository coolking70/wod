# v0.5 潮汐异变：实现与验收

2026-10-31。独立实现的 WoD 灵感原型。本轮新增规则为原创设计，未宣称与 WoD 原版等价；此前检定依据见 V4_RULES.md。

## 试玩入口

点击「载入异变挑战方案」→「开始远征」。保留六名队员与三房间，另提供「修道院·基线远征」用于旧方案回归。切换路线保留配置；载入挑战方案会替换当前配置。历史战报使用出发时快照。

## 召唤

潮术师新增预备技能「唤潮卫」，消耗10法力和1符纸。每位施法者最多保留一名存活的普通召唤物；不能重复施放时不扣资源，并继续检查后续预备指令。潮卫部署于指定站位，其生命为36+技能等级×4，剑术等级继承召唤技能等级，其他属性为模板常量。

召唤物独立被选为目标、执行防御与攻击，使用通用结算引擎。预备阶段召出的单位参与本回合尚未生成的先攻队列；主行动中召出的单位从下回合行动。它们可以接受位置辅助，但远征药膳上限6人且正式队员优先。

主人倒下立即驱散关联召唤物；房间结束清理全部召唤物。通关人数、剩余生命和法力只统计正式队员，召唤物贡献单列。正式队员全灭即失败。每个召唤实例有唯一ID。

## 有限次数道具

每名队员一个携带槽：不携带、凝潮药瓶、救急药匣。药瓶恢复24法力，药匣恢复40生命，均为整次远征2次。实例与携带者绑定，不能共享次数。可按房间覆盖启用状态与30%/50%/70%资源阈值。

本人普通行动到来时：道具检查→独立治疗检查→普通指令。道具成功使用占一个行动，不推进普通指令游标；耗尽后记录原因并继续流程。次数跨房间继承；当前版本没有装备交易、随机物品实例或耐久系统。

## 挑战遭遇

| 房间 | 新压力 | 战术考量 |
| --- | --- | --- |
| 回声侧廊 | 两名护卫掩护后排召潮者，潮卫死后可再次召唤 | 远程优先切断召唤来源；只清前排可能反复消耗 |
| 浸潮蓄水厅 | 中央位置受到两名祭司的群体法术 | 分散站位与集中辅助互相制约；屏障、防御可局部调整 |
| 守誓圣坛 | 首领半血碎印，召出左右翼各一名潮卫，后续普通技能改为法术压制后排 | 保留法力，调整后排防御；击倒主人也会驱散召唤物 |

碎印在一次完整施放结算后检查，首领仍存活且生命不高于50%时仅触发一次。直接击杀不触发。此事件的两名召唤属于首领专用阶段规则，明确例外于普通「唤潮卫」一名上限。

## 验证

运行 `node --test tests/v3.test.mjs tests/v4.test.mjs tests/v5.test.mjs`，共35项。新增11项覆盖：召唤上限与独立行动、主人死亡、房间清理、道具占用行动与游标、次数继承与耗尽、恢复及策略关闭、局部覆盖限制、首领阶段一次性与完整分组、击杀跳过阶段、配置迁移、三个种子资源及确定性。原有24项继续通过。

浏览器验证：挑战种子731通过三房间，6名正式队员存活；关键事件中含敌我召唤、两次药瓶和一次碎印。第二房间关闭道具不影响默认策略。召唤和道具两组A/B均可运行并打开战报。图片、描述、阶段与对应回放事件一致。

样本结果：挑战推荐配置剩余生命526、法力174，药瓶两次均由潮术师使用。仅关闭玩家召唤的对照剩余生命591、法力178。该样本不支持“召唤一定更强”，也不代表多种子平衡结论；召唤改变目标分配、资源和随机数消耗顺序。
