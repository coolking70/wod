# v152 · 独立心理防御与普通培养

本轮把心理防御从只能跟随法术的联动方式，扩展为可以独立、按房间安排的实际选择；不是再增加一种攻击颜色或战报统计。缺省仍联动，明确选择后才写入`defenses.mental`。可选自然防御、原心智抵抗和新增自由普通防御「定心自守」。恢复联动删除该可选键，不删除已培养等级；每个房间覆盖整组防御，清除本房防御覆盖时仍保留其他房间字段。

定心自守只应对攻击方式为心理的攻击，按当前意志×2＋魅力＋实时防御等级×2＋全防御增益检定；每次2MP，不占普通行动，无装备或课程门槛。基础6级、免费防御专修+3、独立永久培养、装备与临时等级沿既有防御规则，只计一次。普通培养仍20/40/60XP三级，能与心智抵抗及其他普通技能同时投入和精确退回。培养不是启用门槛，也不自动启用或代选后期进阶。缺蓝回原自然防御，付费等级/专修不进入自然等级；自然依旧使用本项目已有意志/智力公式，并未移植原版整套自然防御。

法术仍使用法术栏，远程伤害即使走法术伤害通道也仍按远程防御；疾病沿原自然耐病。心理抗性与攻防检定独立，物理护甲仍不减心理伤害。无新敌人、技能攻击、装备、地城、奖金额或永久补给；没有额外检定、主动行动或按命中结果退款。

## 从准备到实际结果

准备页可选联动或独立心理防御，分房选择与整组恢复继承沿同一入口。实际公会出发卡显示按真实装备和培养得到的出发等级、费用及来源，声明是满法力、无临时效果的核对，不预测后续资源。实验草稿+3不能冒充公会已付+1；本轮实卡等级10（基础6/专修3/培养1）对照已验证。

战报只读取本次已记录的选择、回退、属性、等级来源、均值/实掷和实际法力前后值，不用当前公会重算。独立选择、实际使用技能、缺蓝回退皆可解释。命名方案、差异提醒、正式出征、完整报告/历史和整档备份都保留该字段；在独立测试副本中新增第四命名方案并实际整档恢复，前三原项保持，正式接续档仍为原三方案和A。
