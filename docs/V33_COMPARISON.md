# v0.33 历史方案对照

在公会履历的可重演记录旁增加“对比当前方案”。全队变化与六名队员分别展示，变化默认展开、无变化默认折叠。表格左侧为历史，右侧为当前；支持装备、训练、站位、技能专修、指令、治疗、防御、道具、补给、事件策略、协作顺序和相关房间覆盖。

比较对象可切换当前准备方案或当前公会资产＋当前战术。后者仅替换装备与训练，不自动通过技能资格检查；种子展示准备页值，正式出征仍分配新种子。不同路线比较使用双方房间槽并集，并提示战斗环境不同。仅比较相关路线房间，不展示两条路线均不会用到的覆盖；显式覆盖与继承默认仍被视为配置变化。

比较为只读，不模拟胜率、不归因胜负、不更改公会或方案。可使用现有历史方案载入入口继续修改。未新增存档字段和迁移。
