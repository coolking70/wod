# v0.231：命中与伤害的独立培养取舍

本轮补足一项战斗规则表达：武器可为普通物理弓击指定独立伤害属性，命中仍采用原技能属性。玩家可通过测潮重弓观察“更容易打中”和“命中后提高伤害基值”的区别，付款前预览、装备比较、实际出征核对和战报共同解释取舍。没有新增技能互斥、培养货币、共享永久补给或多页面写入契约。

## 原版依据与适用范围

官方技能页 [Bogen schießen](https://world-of-dungeons.de/skill/Bogen%2Bschie%C3%9Fen%26is_popup%3D1%26world%3DWC) 的搜索索引正文分别列出 Angriff「Ge,Sn」和 Schaden「Wa,St」，支持“命中和伤害可以使用不同属性组合”这一结构。Ge/Sn 对应灵巧/敏捷，Wa/St 对应感知/力量。本轮直接读取技能页未成功，证据级别是官方页面的索引正文，不能视为已核验的现行服务器规则、训练花费、精通或数表。工具原回执和限制保留在本轮研究及 DESIGN_LOCK 证据中。

项目旧射击继续使用灵巧/感知命中，未照搬该页的命中组合；旧装备、普通技能、费用和公式不改写。新武器、属性加减、价格和下述伤害公式均为项目原创改编，提前锁定后才运行正常远征，不是原版数值复刻，也未据两次胜利调优。

## 实际规则

测潮重弓占原武器槽、属于弓具，可在原固定商店按每位队员60金币购买一次；再次装备本人已有弓具免费。属性是感知+2、力量+1、敏捷−2，属于需要权衡的替换，不授予永久培养或额外指令。

普通物理远程生命攻击采用：

```
伤害投点前基值 = 当前感知/2 + 当前力量/3 + 实际技能等级/2 + 4
```

随后继续原技能威力、随机投点、命中品质、实际目标的分档护甲、穿甲、抗性、淬药分段、援护、法力护盾及剩余生命截断。当前属性包含实际装备和已生效临时效果，技能等级包含原永久培养、专修、装备等级和临时效果。未增加随机调用、攻击次数或资源支付。

| 培养一级 | 原技能命中均值变化 | 此弓伤害投点前基值变化 | 其他静态效果 |
| --- | --- | --- | --- |
| 灵巧 | +2 | 不变 | 不自动增加指令 |
| 感知 | +1 | +0.5 | 原防御/先攻依其原公式另算 |
| 力量 | 不变 | +1/3 | 原其他技能各按其原属性 |
| 体质 | 不变 | 不变 | 生命上限+4 |
| 相关技能训练 | +2 | +0.5 | 仍支付实际经验，不能绕过技能可用性 |

表中是静态数值变化，不是最终实伤、命中概率、行动次数或胜率承诺。属性页同时列出仍然不变的弓击伤害基值，避免把灵巧命中提升误解为该武器伤害提升；技能培养预览也明确标为“非固定实伤”。

潮印箭的法术伤害、机关拆解、削蓝和无伤技能均不采用该武器公式。淬药的物理主段可使用它，魔法附加段保持原来源与公式。武器定义之外的角色/指令不能注入伤害属性字段。

## 战报与资产闭环

只有实际采用新武器公式的事件新增可选 `damageAttributes` 来源记录，包含当时命中属性、伤害属性及值、等级、威力、武器常数和基值。旧装备不新增空字段。淬药记录保留在物理主段，附加段不伪装成独立属性伤害。原护甲和攻击/防御费用记录仍在原位置。

战报按事件记录展示，不以当前换装重算历史；所有新增来源及看似数字的导入字段均转义。该武器沿用原射手真实事件SVG动作，实际放箭仍只对应原行动。新增原生SVG图标按HTTP状态、MIME、字节和SHA核对；没有声称新生成GIF，也没有用体积测试推断真机更快。

从保留的真实八次结算成长档复制四个原字符串，莱恩原有580经验、已训练穿甲箭一级，公会1395金币。明确购买花60金币、感知一级花20真实经验，继续正常编号9/10；第10次免费换回原校准弓具，不退回感知，不重复购买。第9次16条实际攻击采用新来源（9致命、5重击、2命中）；9、10均通关且六人生还。第9次同种子原弓对照使用相同已付资产和培养，不领取对照奖励。不同先攻和随机消耗不允许把结果差异只归因伤害属性；六套视口也不是六份独立平衡样本。

新版本可完整导入/导出含新物品的当前整档；v0.230不认识该物品，会拒绝相关新档。因此请保留升级前导出，不把新档导回旧试玩站。旧站实际存档迁移、不同源本地存储共享均未验证或实现。
