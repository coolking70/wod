# v0.29 阶段试炼与敌方组合

新增熟练、资深两条三房连续路线。阶段为建议而非门禁，阶段本身不增加属性；玩家可以提前挑战。资源跨房继承。此版没有新增兼容分支，后续不维护旧存档兼容，见DEVELOPMENT_POLICY.md。

## 遭遇设计
- 裂潮哨站，36份补给：后排狙击；中央召唤者抗远程/后排治疗者抗法术；末场重甲旗卫、后排药师和左翼弩手分开站位。
- 沉钟议庭，30份补给：双翼弩手分离、共同射击后排；中央群攻与高法抗治疗者；末场高生命旗卫与互补抗性支援。
- 站位、治疗优先、不同攻击类型的职责目标以及低耗备用指令均影响结果。

准备页提供正面突破、统一职责集火、分工保护三套完整实验方案，可撤销载入，种子保持不变。分工保护为射手指定治疗者、法师指定召唤者，首房按敌阵改变目标；屏障覆盖后排，资深版将学者与药师移出中央。预设不保证最优。公会仍使用实际资产与训练，不凭载入模板获得成长。

场景使用现有插画配合真实房间名与敌阵；没有新增图像素材。治疗/召唤者保留专属画像和类型标记。

最后一组只替换潮术师各房间普通指令中的凝潮长枪为凝水矢，不改其他项。结果支持低耗技能在连续战斗中的潜在价值，不证明普遍最优。方案间多项改变不能作单变量归因，失败场次会截断总回合，不能简单按平均总回合判优。实验配置不是从新公会成长到资深的全流程样本，不能据此认为完整经济/难度曲线已平衡。
