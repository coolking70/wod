# v0.30 公会出征核对

## 改动
公会新增六人出征核对区，准备页的公会出征入口直接定位此处。展示实际公会装备、训练、初始生命/法力，以及战术中的专修、属性专长、防御、道具、救护与预备/普通指令。与准备页模板不同的资产用说明标记，避免把实验配置误认为实际养成。

可切换默认配置和具体房间。点击调整此人战术会直接定位对应角色与房间；点击装备与成长则定位公会该角色成长卡。核对不会修改配置。

提示范围：全路线或选定房间的武器要求缺失、盾牌防御回退、所需补给为零、救护缺药草。未学习进阶技能和未领取远征结算会禁用出征；装备/补给提醒不阻止玩家试验。检查不预测胜负、总法力需求或整次远征是否耗尽资源。

出征仍由原公会逻辑校验和建立配置快照。战斗规则、资产结算、成长门槛与存档结构均未改变，不新增历史存档兼容逻辑。
