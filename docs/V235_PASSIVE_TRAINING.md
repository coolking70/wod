# v0.235 普通被动培养：耐病修习（定向开发阶段）

在已合入 main 的 v0.234/0126ea42 基础上增加普通被动培养，首项是耐病修习。它使用现有共享经验预算：0至3级，逐级20/40/60经验，可精确退回；每级给疾病天然防御均值+4。无需预备/普通指令，不占行动或装备槽，不耗法力、材料，不增加生命、抗性或免疫。普通技能依旧自由搭配，职业进阶独立；主动专修、装备技能等级及临时技能/防御技能等级不会放大这项被动。体质、魅力及真实全防御加成继续独立计算。

培养前可检查当前/下一级/退回后的耐病均值及费用。用途栏明确未学、被动生效、未出战；疾病战报记录当时已付等级及全防御/被动的分项，而不是用当前培养倒推旧战报。撤回后回看历史配置仍会重演当时已付等级，这属于本版本历史配置重演，不是保证跨版本同结果的不可变收藏。原始导出JSON仍分别保存并精确对照。

原版依据有限：官方历史百科的搜索索引分别把 [Health](https://world-of-dungeons.net/ency/Skill_-_Health) 描述为被动疾病防御技能，把 [Quick Thinking](https://world-of-dungeons.net/ency/Skill_-_Quick_Thinking) 描述为被动属性/先攻技能。因此“可以培养且不列入主动指令的被动技能”有历史官方索引依据；本次直读分别502/403，未读取全文，未核实现行服务器。耐病修习名称、所有当前英雄均可学、0至3级、每级+4、费用和排序均为项目改编，不能称原版精确还原。既有孢潮敌技不授予玩家主动指令，被动通过独立付款学习。

从已挣得的第14次末公会继续：A付款20经验后正常第15次雾孢药圃，领取一次；再精确退回20经验后正常第16次，领取一次。两次六人生还；15有6次A疾病检定记录被动，16没有被动。实伤6/13不是同种子因果对照，不作胜率/收益承诺。另有相同已挣总经验、退回被动的15次诊断对照，未领取；没有搜索种子或调整遭遇、参数、预设来过测。
