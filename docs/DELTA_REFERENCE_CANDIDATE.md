# 中文Delta：可替换研究候选

查阅2026-11-05。父线程要求在等待用户指定服务器期间，以中文Delta公开资料作可替换研究参考，继续不依赖具体服务器数值的开发。用户尚未选择Delta；运行profile的referenceServer仍为null。

本轮实际打开[Delta公共首页](https://delta.world-of-dungeons.org/)与[公开技能详情示例](https://delta.world-of-dungeons.org/wod/spiel/hero/skill.php?is_popup=1&key=5rS+55Sf77ya5oqV572R5aSn5biI)。技能详情能分别呈现职业/等级可学条件、阶段、目标人数、材料、检定字段和个别技能上限，适合研究信息结构。这仅是一个技能的公开描述，不足以推出全部职业、当前费用表、精通或重置经济。本项目没有复制其数字或原文技能。

直接请求hero/skills.php及带编码键的技能URL时，工具报告不可访问，HTTP状态不明；随后通过已检索到的技能详情引用成功读取正文。不能将第一次工具错误写成网站403。父线程此前已记录训练花费和精通表需要登录，本轮没有登录、创建账号、请求凭据或绕过访问限制，也没有新增“现行成本已核实”的结论。

已读历史德文百科另见[核阅记录](WOD_DESIGN_REFERENCE_2026-11-05.md)；既有四个HTTP403目标仍保持未读。可验证事实、项目参数与未确认资料分开记录。候选替换不改变运行规则，确认某个服务器也不等于同意迁移现有公会资产。
