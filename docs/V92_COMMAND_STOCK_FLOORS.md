## 玩家可以表达的计划

原先药师药剂和救护争用药草，玩家主要靠每房一次或低耗后备节制，无法直接表达“进攻后至少还留4药草”。现在每条耗材指令可设置**用后留存**：例如药剂所需1药草，当前5份可施放到4份；当前4份时不付款、不占行动、不消耗一次/回合次数，按既有游标规则尝试下一条指令。没有可用普通后备仍真实空过，预备无可用行不伪造等待。想每回合重新检查，仍需选择“每回合一次”；底线不自动重排所有指令。

这是本条指令的用料条件，不是材料所有权/全局库存锁。其他进攻、预备、自动救护和事件按各自规则付费；自动救护可用到进攻底线以下。并不承诺留下的4份最后一定给谁、能救几次或避免多少伤害。

- 编辑器0表示不设底线，序列化时省略；实际字段`keepStock`为1–60整数，只用于原本有共享材料的技能。高于出发库存合法但静态提示可能不可执行，不替玩家改配。
- 默认/逐房覆盖、方案保存/导入/撤销、个人草稿指令采用、pending/历史和完整公会备份沿用现有真实配置通道。伙伴托管职责仍优先于草稿；明确采用为自定义后才使用草稿底线。
- 按媒介实际单次材料检查：标准符纸1、复写2；群体一次付款，不按命中人数重复检查。心诵不消耗符纸，底线保留但不参与，恢复耗材媒介后仍在；改为原本无材料技能会移除无意义字段。
- 港口前两场的事件预留独立、优先检查；第三场只释放港口预留，不会移除玩家逐条底线。敌人若配置底线，只看自己的独立库存，不扣玩家材料。

出征卡片、伙伴预览、静态资源行/提醒与配置差值明确显示底线。战报保存当时库存、实际所需、付款后候选余量、底线和免费跳过；还记录实际后备事件，能直接跳转。用料账本把缺料/缺蓝、事件预留、指令底线分开；复盘按真实底线事件定位。修正原复盘定位落到战场而非详情的问题，现打开行动证据。未设底线的旧报告不新增零字段或改变随机序列。
