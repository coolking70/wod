# v0.117 同房分波增援与潮堤接应

基线v116 `56fcb1af4234693a7bb7ff87854214b0c38c1ab2`，分支`feature/v117-wave-reinforcements`。在已完成一次正常邮路首通后，加入需要跨波保留真实状态的单人内容，重点是同房指令/支援/召唤与余量的延续，没有新增单个技能或装备。

## 分波规则

只有显式带公开增援的遭遇采用新规则，每房首波之外允许1–2个有限增援波次。所有波次、阵位、技能、救护范围和费用在出发前公开，没有随机追加敌人。未抵达的敌人不能被选为实际目标。

当前波敌人（含其存活召唤）全清后，沿原清场方式结束余下普通阶段；旧队列不能提前攻击下一波。回合末照常到期，并记录本波已清、仍有增援。下一波在下个回合原有缓释/持续伤害之后、整队撤退与预备/先攻之前抵达。如果持续伤害在回合开始清掉最后敌人，本回合结束到期后记清波，增援仍要等再下一个回合，不在这次跳伤后立刻送入旧阶段。

各波共用本房累计回合与原24回合上限、指令游标、本房一次次数、生命/法力、道具次数、现存召唤及增益/负面期限；不回满、不退料、不重置。敌方同房材料库存也延续，真正新入场敌人使用自己的初始生命法力。普通回合窗口按本房累计回合，不从每波重新计1。只有全部公开波次清完才算过房，单波没有独立房间收益或通关证明；上限时尚未抵达的增援仍属于未完成。

整队撤退继续按v116规则检查，新波抵达后仍有敌人且存活正式队员达到阈值时会撤退；不会把前波清场当作本房胜利。没有永久材料、波间休息/购买、复活或中途改配。

## 两场单人接应

- 雾堤接应：首波前排两名钩卫受后排鼓手一次节拍支援；第二波前排追浪守卫、后排接应医师和右翼射手。首波没有医师，公开增援才出现，治疗者追击需要在实际到场后重新检查；同一条“本房一次”穿甲/群攻不会因新医师抵达而重装。
- 复灯堤台：首波护灯者援护左翼刻灯术士；第二波前排重卫与两名后排齐射手。群攻转向后排，已有屏障可能在到期，普通指令的窗口和游标保持，需要用整房计划应对。

三个可改起点同为30携带补给：本房一次强攻与急拍、按实际医师到场追击、低耗持续/少急拍。它们改变多项决定，不是单变量强弱结论；不送装备/培养/课程，不改公会已应用的伙伴职责，保留种子、目标及显式整队撤退计划，可撤销。

新路线仍两房，因此首通40房间金币+60通关+50首通，共150金币/每位65经验；重复100金币/每位45经验。无装备掉落，未完整清房不领取该房20/10。普通攻略只记首次实际成果，不发额外奖励。24路线/40装备/72个普通攻略目标。

## 证据与呈现

准备页和实际出征卡将威胁按波分别列出，采用各波模板候选，不将所有波次相加为同时攻击次数；首波缺少职责目标时明确提示公开增援可能新增候选。实际指令预览仍只列首波候选，不假装能提前攻击未来医师。未来敌人的头像/治疗者标识来自公开模板，抵达时显示“增援抵达”，不会把普通敌人标成召唤物。

默认、精华和个人回放保留清波/抵达边界。抵达记录保存上一波清场事件ID、实际新增单位及敌方剩余库存，可精确往返查看清场来源，不推算假想伤害或胜负贡献。房间结果显示进场波次与完成数；历史报告保持当时实际配置，观察/追溯不会改待领奖励或当前资产。
