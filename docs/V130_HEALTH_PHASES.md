# v0.130 生命阶段与易相灯庭

v129已分开攻击方式与伤害通道，但大部分敌人的攻击免疫和普通指令整房固定。旧破誓者已有专用半血碎印反应，本阶段保留其原行为，另增加公开、有限的生命阶段模板，让不同输出与保护职责需要在一场内接力；不是继续添加一个换色技能。

## 转态结算

模板最多两个阈值，必须从高到低。单次实际生命伤害及其附着处理后，受击敌人仍存活且首次生命不高于阈值时，依次触发；潮蚀实际跳伤同样检查。直接击倒不转态、不锁血；零实伤不触发，削减法力不是生命伤害。治疗越过阈值不会撤回或刷新已经触发的阶段。

每阶段只替换公开预备/普通指令和攻击类型免疫，不改属性、抗性、护甲、阵位、治疗策略或技能等级，不回血回蓝、不补材料、不移除原状态或召唤物。已有队列/回合编号/行动总数保持；轮到敌人已有普通行动时用新指令，新的预备等下次正常预备。阶段反应本身不掷骰或额外收费。阶段有自己的指令游标/阶段内一次，避免旧阶段同序号once误阻止新指令；不重置玩家、本房资源或已发生结果。

免疫仍按攻击方式，不按伤害通道。潮印箭即使造成法术伤害，也不能攻击转态后的远程免疫敌人。固有免疫不能破印驱散；状态和现有伤害规则仍适用。成功援护只有实际受击守卫检查阶段，原保护对象不会凭空损血转态。

准备页敌人档案公开全部阈值、后续指令和免疫，范围核对把各阶段列为条件候选，不相加为同时攻击。实际health-phase事件保存来源事件、当时生命、前后指令/免疫；回放状态提示和单位检查器读取当时记录，不按现在公会推断。
