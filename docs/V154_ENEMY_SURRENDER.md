# v154 · 渡口招抚与敌方投降

本轮提供“击倒以外如何完成一场遭遇”的可玩选择，而非继续增加嘲讽变体。新增两房单人路线渡口招抚，不增加技能、装备、队伍人数或永久资源。清掉其他守军后，公开头领可因攻击削弱或法力耗尽而在低生命时投降；也可以直接击倒，仍按普通规则清场。投降没有额外金币、经验、掉落、招募或永久资产。

## 规则、来源与边界

投降与本路线是项目原创。查询官方历史站点未得到足以支持此规则的原版资料，不宣称原版或现行Delta具有同样机制。沿用的是项目既有的战前配技、职业协作、真实攻防/资源和可解释战报框架；所有新阈值和敌方数值均原创暂定。普通技能自由培养、独立后期进阶与可切换本人保持；补给经济继续待用户。

条件仅来自遭遇模板，不是玩家可勾选的必胜设置。指定头领须是最后一波唯一存活敌人（其他存活召唤物也算敌人），生命大于0且≤公开最大生命45%的整数界线，同时有生效的负面攻击均值/攻击技能等级效果，或原有法力上限大于0、当前法力恰为0。每次完整普通行动后检查，不在群攻两条伤害之间插入，不增加随机、行动或费用。动摇、旧挫志及缴去法力提供不同准备方向，不要求唯一职业；强攻仍可通关。

投降者从活动战斗集合移出，保留HP和投降时状态的只读快照，不伪造死亡、治疗或复活。旧队列、攻防和资源记录不回滚；尚未释放的蓄能取消、已付费用不退。之后不再行动、受击、参与支援或重复投降。战报明确标为“已投降·退出战斗”，显示生命前后值、界线、实际条件来源，并可跳到条件满足前的完整行动；个人和精华回放保留这个全局节点。房间结果记录真实投降者，不把其计为第七名队员。

第一房哨长220HP、公开界线99；第二房书记200HP、界线90。先清前排，再选择压低头领生命并削弱、缴蓝，或直接强攻。两房30补给，普通重复100金币/45XP、首通140/55，无掉落；没有专属招抚奖励或额外费用。
