## 来源

本版自主实现，没有复制第三方源码或资料包。结构研究参考 dust1/wod_local，固定提交 a710c1416e127b07977d8f5d2728e8eac1303fbc：
https://github.com/dust1/wod_local/tree/a710c1416e127b07977d8f5d2728e8eac1303fbc

第三方测试通过不证明原版正确。本版不是完整 WoD 复刻，也未使用其名义声称公式已经验证。

| 规则 | 本版行为 | 依据性质 |
| --- | --- | --- |
| 属性与技能检定 | 主属性×2+副属性+实时技能等级×2 | 第三方实现参考，待独立原版资料复核 |
| 基础伤害 | 主属性/2+副属性/3+实时技能等级/2 | 第三方实现参考，待独立原版资料复核 |
| 命中档位 | ≤防御闪避；≤1.5倍命中；≤2.25倍重击；其余致命 | 第三方实现参考，边界待独立复核 |
| 随机分布 | floor(均值×(0.5+(U1+U2)/2)) | 原创试验规则，范围约均值0.5–1.5倍 |
| 先攻 | 均值=敏捷×2+感知，投点后按1/(1+0.6×已排行动数)衰减 | 均值参考第三方，衰减原创；未采用未经独立复核的32步循环 |
| 平局 | JS稳定排序保留队伍输入顺序，玩家队伍在敌方之前 | 原创试验规则 |
| 防御 | 普通攻击敏捷×2+感知+10；法术意志×2+智力+10；加临时防御 | 原创；尚未实现独立防御技能 |
| 伤害顺序 | 属性/技能→基础伤害→技能倍率→投点→档位倍率→固定护甲→向下取整→扣血 | 原创；显式固定顺序，不提供无效的阶段排序参数 |
| 档位倍率 | 命中1、重击1.25、致命1.5 | 原创试验数值 |
| 治疗 | 行动点检查最低生命比例目标，成功占行动、不推进普通指令；失败回到普通行动 | 第三方结构参考；50/65/80%阈值与治疗均值×0.7为原创 |
| 同名效果 | 同一目标同技能不叠加；部分目标未覆盖仍可施放 | 原创明确约定，尚非完整原版互斥体系 |
| 持续N回合 | 当前回合及后续N回合，在最后回合末移除 | 第三方语义参考，待独立复核 |
| 房间/远征效果 | 房间结算移除非远征效果；远征药膳跨房间保留 | 第三方结构参考，内容原创 |
| 消耗 | 玩家共享补给，总预算60；敌方每房间独立补给；MP每回合回复1 | 原创简化；未实现装备实例次数 |
| 失败 | 一圈指令均不可用则空过，不自动普攻；未执行指令不扣费 | 第三方结构参考 |

## 本轮验收

`node --test tests/v3.test.mjs`：12项通过，其中一项运行20个种子。检查先后手、技能增益、治疗中断/资源不足、同位置AOE、跨房间状态、耗材与备用指令、独立到期、溢出伤害、确定性、配置拒绝与回合上限。

浏览器实际执行：保存A→学者上移→同种子比较、打开远征、单步回放、切换房间。种子731：首次屏障23→15；默认配置3房间通过，药师4次治疗中断，有效治疗196。此结论是单种子机制示例，不是整体平衡结论。

## 范围与后续

为集中验证机制，本版收敛为六人三房间；v0.2仍保留于 legacy.html，配置存储独立。v0.2有而v0.3暂未迁入的逐房间配置、12人队伍和20种子可视化比较不视为已完成。

本版每个增益只有一项修正，但每个效果分别保存来源与期限；未声称完成多组件效果账本。延迟生效、召唤、独立防御技能、装备实例调用次数、完整成长掉落和多人尚未实现。

下一步顺序：
1. 独立防御技能与多组件/延迟效果，以原版资料建立可核对样例。
2. 逐房间战术覆盖、按装备实例记录耗材使用次数。
3. 扩充有结构差异的敌方策略与地城目标，之后再扩职业及长期成长。
4. 同一事件流驱动角色立绘/特效/事件CG。当前仅使用已有AI背景与站位卡片高亮，没有在线生成CG或角色动作。
