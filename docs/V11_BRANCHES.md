# v0.11 沉钟分途

## 目标与范围

让非战斗检定影响后续遭遇。当前仍为固定三房间，分支只改变末房阵容或属性；不声称已有自由地图与剧情生成。沿用原有AI插画，本版新增路线结果面板而未新增CG。

## 规则

|前置结果|末房路线|真实变化|
|---|---|---|
|解读成功|密文 · 破印路线|全体敌人法术抗性减少20个百分点，当前0变为-20（弱点）|
|破拆成功|侧门 · 惊动守卫|避开aa4护印师；aa1/aa2/aa3守印者力量13变17|
|失败、绕过、无合格队员或缺补给|正门 · 原封印|保持原有四名敌人|

第二房间的房间防护仍按v0.10清除，路线收益独立记录并在第三房间进场时生效。无额外投点或材料费用。没有抵达末房时不触发路线事件。每次模拟均克隆敌人模板，后续运行不继承变更。

route事件保留sourceEventId、sourceRoomIndex、路线名和逐敌人变化清单。第二房间原始encounter作为因果来源；后续手动改配置或播放回放无法改写结果。第三房间room快照先记录原阵容，紧随其后的route快照应用分支；双方开始任何行动前已完成变化。

## 玩家界面

准备页提前显示成功路线后果，并注明敌情卡为正门基础配置。关键事件包含末房路线；结果面板显示前后差异和“追溯沉钟检定”按钮。路线事件使自动播放暂停。战术实验显示实际末房路线。

## 验证

87项自动测试全部通过（新增8项）。覆盖迁移保留策略、成功条件、模板无污染、避开指定敌人、力量修正、魔法弱点进入真实伤害、来源事件、费用不重复、未抵达不触发、纯回放与复盘定位。

浏览器验证：载入沉钟方案、种子42，解读成功进入破印路线；追溯按钮返回塞恩79/70的原始检定。改为破拆后，末房显示护印师绕过、三名守印者13→17。截图见V11_BRANCH.jpg。现有79项回归保持通过。

## 下一步

当前内容仍是一条预设事件链。下一轮应补充一类不同属性/资源需求的事件（例如救援或补给），让队伍职责与路线之间出现更多取舍，再考虑图形选路和更多插画。尚未做大规模多种子平衡评估，不以单个种子的胜负断言某路线最优。
