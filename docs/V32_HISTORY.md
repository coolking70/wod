# v0.32 远征回溯

领取奖励后仍保留最近20次出征的配置快照：路线、种子、各人的装备训练、默认指令及房间覆盖。履历提供“重演”和“载入方案”两个入口。

重演使用当前模拟器，读取独立快照，不读取当前队员装备，不写公会或发放奖励。相同规则下结果与领取前报告一致；未来修改规则后可能不同，界面明确标为按当前规则重演。它不是跨引擎版本的原始事件档案。

载入方案沿用准备页可撤销替换流程。再次公会出征仍由当前公会资产覆盖装备训练，重新检查技能学习资格，使用新出征序号对应种子。没有快照的记录仅展示结算；没有新增迁移或旧档专项测试。
