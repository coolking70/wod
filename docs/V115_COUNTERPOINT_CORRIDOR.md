# v0.115 错拍回廊

基线v114 `8967d734b7a4842adb42fe9b32fbce2f12d6e783`，分支`feature/v115-counterpoint-corridor`。继续单人战前配置、整段自动结算；可切换本人、小名册、托管伙伴、普通技能自由培养与独立后期进阶保持。没有永久补给、服务器或发布变更。

## 从实际失败选择下一步

v114两次邮路都在末房失败，保留前两房40金币/20经验，没有首通或遗物。末房持续节拍、护印和10/13次敌方救护仍在，玩家药草耗尽；不能从“少排了一次额外行动”推出解决了整队压力。没有修改邮路敌情、奖励、迟拍数值或挑种子。此阶段选择独立两场练习短线，让敌方也使用相同迟拍规则，练习额外行动的收益、拆来源、净化机会及资源代价，再由玩家选择是否重返高压路线。

## 两场可玩内容

1. 迟声门廊：两名前排守卫与后排迟声乐手。乐手每回合检查迟拍，只有当玩家已获得额外普通行动且无迟拍时才付7法力选择目标；否则免费走射击后备。命中后只影响下一回合，基础和当前队列继续。指定位置没有合格者仍按普通位置路线回退，不能把单纯移位当成免疫。
2. 护弦走台：迟拍来源移到左翼，第2回合起检查；前排护弦者援护左翼，物理追击可能被接招，法术/心理不触发。后排术士第3回合起一次潮汐冲击压前排。净化须在排队前实际移除负面，占学者预备、4法力与1共享符纸；来源后续有机会重施。击倒已经命中过的来源不会撤销旧迟拍。

三个可改起点使用相同24份携带预算：急拍推进承受限制；保留急拍、学者净化优先并以屏障后备；少用急拍、按房追击后排/左翼来源。它们改变多项指令，不是单变量最优结论，不赠培养、装备或课程，不改已应用的伙伴职责，切换保留种子和已选目标，仍可撤销。

本路线仅金币/经验奖励，无装备掉落。每通过一场20金币/每位出战者10经验；通关另35/15，首通再35/15，即首通110金币/每位50经验，重复通关75/35。失败只领通过房间的收益，不发通关/首通加成。额外攻略目标只记首次证明，没有额外奖励。23路线/40装备，共69个普通攻略目标。

## 确实改善的反馈

敌方预备及普通指令现在直接列出实际法力、材料数量和“敌方独立支付”，补齐敌情只显示技能/等级/均值而未列费用的缺口；自动救护继续沿原有独立库存说明。入场没有迟拍候选仍明确提醒辅助之后要重新判断，不预测胜负。

个人复盘增加本人实际少排次数及代表队列证据。开启“只看观察角色相关行动”仍保留该角色受到或施加迟拍的真实队列；选择观察A不会切换公会本人E。代表证据沿既有设计每类保留首条，数量汇总则按所有实际记录累计。新筛选支持没有detail的简化事件，不影响其他行动/房间边界。

## 正常成长和反例

从v114的真实265金币档、两次失败后接续，不改seed或注入资产。本人仍E，已拥有的潮刻怀表和已付费迟拍培养保留。

- 正常编号4，急拍推进，4/4回合六人生还，敌方迟拍施放3次，实际两条2→1队列。正常领取110至375；随后支付D本人已有经验20培养屏障一级，未免费训练净化。
- 正常编号5，净化优先，4/4回合六人生还。真实净化4次，每次4法力/1符纸，保留原节拍；后来仍有重新附着。符纸耗尽后末段实际少排1次，不能称净化永久免疫或保证零限制。领取75至450。
- 正常编号6，少用急拍并逐房拆来源，4/4回合六人生还，敌方迟拍0次，免费走后备；护弦者对物理追击三次援护均未及，仍各付2法力。法术按原目标结算，不把失败尝试冒称成功挡伤。领取75至525。

三个实际首证来自4/5/6，旧邮路失败履历和完整报告没有重写，也不能重复领奖。完整案例及资源见[V115_PLAYCHECK.json](V115_PLAYCHECK.json)。另有3方案×seed1/2/7/19/73/731的18个预定空培养输入，均通过六人生还，拆来源组18次援护尝试均未及；这只是短线的有限证据，保留净化符纸耗尽/仍受限及拆来源援护失败，不宣称全局平衡、迟拍普遍升级或邮路已可可靠通过。同种子不代表不同动作后的逐攻击随机数配对。
