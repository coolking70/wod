# v0.119 定点与后备

从干净v0.118 `cd01dcc86f144bae4af933d7f96d522a76f778e2`，在 `feature/v119-strict-position` 本地接续。修改前906测试通过。main仍v0.100，本轮不推送、合并或部署；永久补给已征询用户，回复前不实施。

## 实玩问题与改动

v118两次正常合流都用尽8箭。现有明确阵位的远攻语义是“先这个阵位，空后转其他阵位”，因此昂贵重箭仍可能继续用于其他敌人。既有用后留存可以保住余量，但不能表达“只用这条指令拆后排，后排空则换后备”。

新增可选逐条 `onlyPosition:true`，用于明确阵位的远程、法术、心理单体/同位群攻。未启用保持原来的阵位后备，不改既有配置、技能、费用、敌情、掉落或伤害公式。近战、全体/自身/友方、职责追击和个人阵位优先不提供此开关；职责追击本来就检查该职责的合法候选。

- 只在指定敌方阵位的合法存活候选中按原人数上限/洗牌选择。破印/迟拍的资格筛选仍先有效；不追到别处有资格的敌人。
- 空阵位免费跳过本条，未支付、不消耗普通行动、不抽战斗随机数；下条按原费用与行动规则执行。全部指令无效仍照原队列计一次普通行动空过，不自动赠攻击。
- 有此条件的阶段，每个新回合从首条重查；回合内沿既有游标、行动数、once/round记录。本房一次在同房增援后不重开；以前空目标未成功的once可在下一波实际到场后执行。
- 窗口、已执行标记、装备/禁疗/召唤、法力/材料/预留/留存等既有先行检查保持；再检查指定阵位和人数，实际施法才扣费。人数不足不跨阵位凑数，留存和阵位限制不是同一条件。

这是一条可选战术语义，不能保证省料、达标或通关。每新回合重查会改变原本停在repeat后备的节奏，选择前应读完整规则；不是免费重置已用技能。

## 界面与证据

编辑器默认/房间覆盖可选“仅指定阵位，空则查下一条”。切换为不支持的技能/目标会清除此字段，关闭时删除字段；导入只接受true，拒绝false/字符串或不适用组合。继承仍按原逐阶段覆盖方式。

实装出征卡、伙伴真实候选、共享材料配置表、配置对照和复盘显示条件；初始空阵位有只读提醒，公开增援可能增加候选。预览不试演、代付或改变伙伴职责。

原始战报记录当时阵位、全部合法候选、技能上限、是否为空以及本次实际后续事件。默认/精华/个人（当事队员）回放保留空阵位检查；可到真实后备再返回。链接验证同人/同房/同回合、事件顺序及技能/类型，拒绝错连；换报告清返回状态。检查是免费条件判断，不计施法/失败或虚构节省材料量。留存已满足但随后被阵位/人数条件跳过时，明确显示本次未付款，避免把通过某一条件当作实际扣费。

没有新增高阶技能/装备/路线/训练费用、持久物资或补货任务。战斗规则版本沿既有值，配置仍为已有版本，可选行字段；严格控制只影响明确启用的行。
