# v0.16 补给取舍实验

不改战斗规则（仍为0.14.0）。新增可复现的12组方案与384次固定种子结果，页面支持救援筛选、逐种子结果、载入完整方案并撤销。所有方案来自现有玩家配置能力，没有模拟器特权。

## 控制变量

按房间应对构筑、绕过沉钟、相同训练和装备。2携带×3指令×2救援×32种子：

- 携带为药草/符纸/箭矢8/8/8或4/10/10，总计24。
- 持续主力沿用按房间应对；一轮主力将射手/潮术师的耗材普通指令改为本房一次，其后低耗；全程低耗则用穿石箭/微光，沿用各房首条指令的目标阵位。
- 其他四人、预备指令、治疗与防御保持原样。微光依然消耗MP；屏障依然消耗符纸。“低耗”不是全队零消耗。
- 救援赶路或救治分别列示，沉钟统一绕过，不外推至破拆/解读。

## 赶路组结果

|携带|指令|通关/32|全部目标/32|通关平均剩余草/符/箭|
|---|---|---|---|---|
|8/8/8|持续主力|32|0|6.7/0/0|
|8/8/8|一轮主力|26|0|6.4/0.6/5|
|8/8/8|全程低耗|19|19|6.4/2/8|
|4/10/10|持续主力|32|0|2.7/0/0.6|
|4/10/10|一轮主力|26|26|2.4/2.6/7|
|4/10/10|全程低耗|19|19|2.4/4/10|

储备目标可达，但清场与节省资源存在取舍。持续使用主力会继续消耗增加的弹药；调整执行频率后，更多携带才转化为结算储备。一轮主力4/10/10在救治组变为25/32全部达成，说明减少药草还会影响事件和治疗余地。

样本中的通关均为六人生还，因此全员目标当前没有额外区分度。这是下一阶段内容压力设计需要处理的问题，不能声称三个目标都已平衡。32个固定种子只支持本轮比较，不是总体胜率。相同初始种子不保证改变行动后所有投点一一对应；统计不作单次随机数归因。

剩余补给均值只包含通关运行；失败提前停下不会抬高“节约”表现。无通关显示空值。原始样本仍包含所有失败结果，可下载检查。

## 复现

运行 `node scripts/sample-v16.mjs` 生成dist/samples-v16.json。配置工厂为dist/expedition-reserve.mjs，页面载入与采样共用。

页面：战术实验 → 储备实验，赶路、种子1、4/10/10每房一轮主力 → 载入 → 开始远征，三目标全部达成，剩余2药草/3符纸/7箭矢。载入保存一次撤销机会，不自动出发、不覆盖A方案。

115项测试通过：12方案合法、预算相等、配置独立、改携带仅改库存、改策略仅改两人普通指令、失败排除及空样本均值、384条汇总核对、12组首个种子重新模拟一致。浏览器核对筛选、种子切换、载入与实际结算。截图V16_RESERVE.jpg。
