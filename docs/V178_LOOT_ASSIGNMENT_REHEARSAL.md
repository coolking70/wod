# v0.178 仓库遗物分配试演

玩家可以先比较共享仓库的遗物交给当前出战者前后的实际出征报告，再明确决定是否分配。它衔接了失败复盘、掉落、配装和下一次出征，避免只看面板猜测；规则、物品数值和掉落不变。

## 玩家操作

装备页未持有的仓库卡片提供“试演分配”。同一下次出征种子、真实公会资产和同一战术，调用普通分配 API 的副本得到新配装；两份完整战斗报告保留自己的视角。并列显示普通通关、所选目标、人数、已遭遇回合和实际补给。逐房表可展开，计划名称与两列实际遭遇名称分开；到达时补给不足而退回备用通路也显示真实名称。未到达保持空缺，较早止步的低回合数不当作效率优势。

试演和“回到此件装备”都不写入四个游戏存档键、不出征、不扣库存、不发奖或新增攻略。键盘回到卡片标题，分配按钮仍需明确点击。待领取、已持有和候补不开放此试演；公会、准备或接收者变更使结果过期。跨页 storage 事件立即收起旧操作，动作入口仍重新核验。模拟写失败保留原资产与试演。这是浏览器同步检查，不是跨进程锁。

## 实际流程和局限

固定原长期档13635金币/next129，未换装的正式129通关，5人生还，4/4/9回合，草药0/符纸3/箭矢2。正常领取135金币、每位出战者55经验及邮铃；终档13770/next130/E5815/贝芮尔2700，普通通关不等于“全员归航”目标达成。C/A原文、三方案、五收藏793208编码字符、装备、旧书/故事/职责保持；仅正常增加邮铃1件、通关次数1次。

两个候选在观察前选定：塞恩分配滤露面纱后同129有6人生还、16回合、余量0/4/3；贝芮尔分配圣匣重盾后2人生还、24回合、余量0/3/2。不能推断胜率、通用升级或单项抗性的独立因果。只有独立副本明确真实分配时滤露面纱1→0，旧装备仍持有；该副本普通出征全文与试演相同。它与原装备规范终档分别保存，没有自动采纳较好结果。重盾战报的原生守卫确实没有佩剑，不借用旧佩剑GIF冒称匹配。

另一个显式船底/初始2箭副本在第一房后余1箭，按既有到达规则退回折帆/封蜡。复查发现新表最初只列计划房名，已修正为每列实际名称；旧全文报告与结算不变，保留错误证据并补单位及浏览器回归。

这是本项目的配装辅助与确定性试演设计，不宣称是原版WoD的现行服务器功能。角色自由普通技能/独立进阶沿用已确认方向；没有引入永久补给、改变经济、训练或战斗数值。
