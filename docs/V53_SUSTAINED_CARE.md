# v0.53：缓释照护与共享药草

2026-11-04。从v0.52 52adecb（333项基线通过）继续。本阶段是本轮第四个连续本地增量；v0.49已按批准推送，之后没有额外推送、合并或部署。

## 可玩的变化

两名药师可选基础辅助“缓释药敷”：预备时消耗4法力、1药草，覆盖一个阵位最多3名存活友军；下一及再下一回合开始各恢复8生命，不能复活。固定量不随训练提高，同名效果等待/生效期间不叠加，房间结束清除。没有新增解锁门槛、装备、奖励、费用或敌群，默认方案不使用它。

现有伙伴职责可选“缓释照护”：为前排持续敷药，普通指令攻击治疗者/前排，50%阈值时才进行紧急自动救护。角色仍使用实际装备和训练，专修救护；技能不需新进阶学习。玩家可沿v0.51修复的入口切自定义，改阵位或改为本房一次。此职责是可选战术，不是推荐的候补升级。

缓释由已支付的效果在回合开始恢复，不占普通行动、不推进普通指令、每次恢复不重复扣药草或法力；先激活延迟效果、再恢复、然后进入预备。它无法救首回合即倒下的队员，施法者倒下不撤销已敷给其他存活者的效果，受敷者倒下不能被恢复。既有禁疗只限制自动草药救护，不能阻止药敷、随身药匣或普通行动。

战报记录每个目标的实际恢复和未生效量，从精确效果ID可追到原始药敷并返回。个人面板将缓释实际量、未生效量及目标恢复记录条数单列，实际量已含于总治疗；不把条数当施法次数或普通救护行动。账本仍只按真实施法收费，群体覆盖及后续触发不会重复收费。

## 结果：减少行动占用仍可能更危险
