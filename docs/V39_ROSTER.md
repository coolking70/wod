# v0.39 招募名册与出战阵容

2026-11-01 用户确认采用小规模招募名册。本版完成角色身份/职业模板分离与首批两名候补。

## 规则与入口

公会新增“招募与出战”。一位主角与五名伙伴出战，其他已招募角色留在候补。主角不能被换下；需先切换主角身份。远征待结算时禁止招募与换人。

- 米菈：学者，完成1次远征后支付60金币招募；默认延时护印保护中央。
- 奥林：药师，完成2次远征后支付60金币招募；默认治疗专修、80%阈值救护。
- 两者均为同职业的独立角色实例，可与原学者或原药师同时出战。没有额外隐藏数值优势。
- 当前只有出战者获得经验；候补保留已获得的装备、经验、技能学习与个人战术。招募不自动换人，不能重复扣费招募。
- 候补现用职业示意头像，未宣称完成独立角色美术。

## 数据与一致性

CLASSES保存职业能力与基础属性；CHARACTERS保存角色ID、名称、职业归属、头像与招募条件。HEROES是供规则消费的组合视图。首批实现有名有姓的有限名册，不是无限随机生成NPC。

公会保存lineup及每名角色的tactics。换人时保存原角色草稿；出征投影依据当前六人名单，补齐新角色并同步默认/逐房预备顺序。装备与永久训练仍以公会实际资产为准。职业进阶与预设通过职业模板映射，同职业成员分别学习和消费资源。

机关按职业选择候选；救援由实际出战且存活、治疗均值最高的药师承担，同值按出战顺序。战报、个人反馈、观察角色列表、历史对比、装备分配和成长界面支持新增角色。历史保持出发阵容和主角身份，重演仍按当前规则。

新公会存档使用v4和独立键，准备草稿也使用新键。遵照用户约定不迁移旧公会；原键未删除。移除两项已不适用的旧公会迁移测试，没有为旧存档新增兼容分支。
