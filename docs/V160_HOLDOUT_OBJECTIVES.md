# v160：退潮坚守

补齐“必须击倒全部敌人”之外的可玩房间目标：等潮旧栈桥公开3个完整回合，退潮引航道公开4个完整回合。提前清场也通过；否则在最后一回合完整结算之后，至少一名正式队员仍存活，就可随潮撤离。玩家仍在出发前配置、整段自动结算，不在途中暂停或手动救场。

防护、削弱、救护与清源输出因而有了不同的直接用途。保护起点只把普通行动设为等待，保留原预备与自动救护，仍真实支付材料与法力；可继续自由改配，不增加技能、等级、装备、互斥培养或持续费用。有限两房30补给，新路线普通首通140金币55XP、重复100金币45XP，与既有两房路线同档；没有额外坚守奖或装备。地图36路线/108攻略槽。

回合开始不算完成，完整施放和队列照常结算；最后一回合全员倒下仍失败，战前主动撤退也不算通过。存活敌人保留实际HP，不虚构击倒或伤害；房末原有召唤清理和效果到期规则保持，原生命、法力、道具和补给继承。带坚守的作者房间只支持单波，不混投降目标；玩家不能在配置里注入计时。普通房间不带新字段时保持原结算与战报字节。

出发核对公开两房条件；回放只从当前房间进场记录和已结束的回合取进度，原始结尾显示“坚守撤离”、剩余敌人及真实生命。当前规则目标、攻略册、逐项缺口及结算都使用“完成公开条件”，避免把通过误写为全部肃清。没有从未来事件推断结果，旧路线目标原文保持。
