# 已确认方向：个人英雄＋托管伙伴

2026-11-01：用户确认选择前一种，即个人英雄＋托管伙伴。v0.37 已实现首阶段，详见 V37_HERO.md。以下保留决策背景。

v0.36 已打通回放、证据、调整、公会出征核对、结算与历史重演。下一阶段要确定玩家主要扮演谁，再扩展创建角色、装备归属和职业成长入口。

此前选择的固定公会成长方向仍保留。本次不是重选公会是否持久化，而是确定公会内角色的控制与养成重心。

| 方向 | 个人英雄＋托管伙伴（推荐） | 六人全队指挥 |
| --- | --- | --- |
| 玩家身份 | 明确拥有一个主要英雄 | 公会指挥者 |
| 主要操作 | 自己的技能、装备、条件指令；伙伴使用职责预设 | 六人的技能、装备、指令均由玩家配置 |
| 下阶段交付 | 选择主角、个人成长页、伙伴预设及队伍协作提示 | 队伍构筑页、成套配装与批量指令、阵容切换 |
| 保留深度 | 保留高级队伍编辑与完整战报 | 延续现有全部控制能力 |
| 后续方向 | 为异步协作预留角色归属；不立即引入在线多人 | 以单人队伍构筑和地下城挑战为核心 |
| 代价 | 要设计伙伴托管边界及个人贡献反馈 | 六人维护负担较高，个人角色代入较弱 |

推荐个人英雄＋托管伙伴，因为用户希望更接近WoD的角色专精与协作体验。这是产品方向判断，不意味着托管伙伴等同于真实玩家协作。

需要现在决策：角色创建、奖励呈现、装备所有权与训练导航都会随之改变。当前版本保持六人全队控制，不提前迁移或删改公会资产；确认方向后才实现下一阶段。两种方向都不要求现在引入账号、服务器或实时多人。
