# v0.129 攻击方式与伤害通道

原先技能的type同时决定命中、防御和伤害抗性，射手无法在保持远程命中路线的同时选择其他伤害抗性。本阶段将这两项分开，并用一个自由普通技能实际验证；不新增元素、伤害分段、地城、装备、资源或永久补给。

## 两条真实结算路线

- 攻击方式type仍决定目标路线、阵位/职责、应对防御、是否尝试援护和固有攻击类型免疫。远程攻防仍按远程，不因法术伤害而绕过物理援护。
- 可选damageType决定命中后实际受击者的伤害抗性；没有此字段的全部旧技能继续用自己的type。实际接招成功后使用接招者的抗性和护甲。原护甲政策保持：心理通道不用物理护甲，其他通道仍用；跨通道不额外穿甲。
- 既有immuneTo是攻击方式免疫。法术攻击免疫不会阻止远程方式的法术伤害；远程攻击免疫会阻止这种箭。不是伤害免疫或100%抗性。接招后发现实际目标攻击免疫，保留已付费，不再防御或受伤；未被选为目标的免疫者不会引起收费。
- 通道来自固定技能定义，指令不能填写damageType改数值。双方沿同一引擎；敌方验证使用专门合法遭遇，现有敌人模板不改。
- 施放/防御/攻击仅在方式与通道不同时保存可选独立记录；准备/预览、敌情、受击说明、事件检查器与回放均显示两者。回放读取当次记录，不按当前技能重新猜测。本人跨通道实伤属于已有总实伤子集，不重复计入。

## 自由普通技能：潮印箭 arcshot

射手使用弓具，主灵巧/副感知，威力1.15，4法力/1箭矢，占普通行动、单体。远程检定/闪避/援护/攻击免疫，命中后法术抗性与原护甲；不附状态、不恢复法力，不保证伤害高于重箭。闪避仍支付本次费用；弓具、共享余量、目标职责、阵位限定、回合窗口与原后备继续生效。

普通技能不互斥，可自由专修/20XP培养第1级，沿原20/40/60与永久+3规则；不会改变独立职业进阶。只增加射手的可用技能清单，旧默认指令不自动加入。实验+3培养/未拥有长弓不会赋给实际公会；出征按本人实际装备/永久培养覆盖。
