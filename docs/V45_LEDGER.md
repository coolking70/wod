# v0.45：队员用料账本与阵容验证

2026-11-02。延续战前配置、整段自动结算及常规方案自主推进。

## 实现

港口完整复盘增加逐房折叠账本。每名实际出战角色独立列出技能耗蓝、防御耗蓝、药草/符纸/箭矢支出、缺资源跳过、预留跳过、普通行动空过。按技能展开成功施放次数与消耗，并可定位首次施放或首次资源不足。

共享物资按成功施法计一次，多目标攻击或增益不重复计算。分支事件费用/收益另列，不算入检定角色技能费用。法力为累计支付而非净变化；恢复与道具依原始记录查看。召唤物不计入队员个人施法支出。当前UI限定港口；通用账本函数的事件对账范围也是港口branch事件，不用于宣称其他路线的完整收支。

“从战报调整”载入本次出发配置、冻结方案A、定位角色与房间；不自动改写指令，不自动出征，不改变公会资产或奖励。复用原复盘编辑流程。本轮不修改战斗规则、随机数、职业数值或存档结构，沿用现有美术。

## 96次阵容与训练比较

`node scripts/sample-v45.mjs`。三阵容×两训练档×两通路×8种子。固定风暴、职责分工、尝试解封、预留2符纸，初始共享补给一致。同一阵容的训练对照保持装备、道具及战术不变：未训练 versus 每人专修技能+2、防御专修+2（共6点）。这不是所有成长方式，未包含进阶解锁或装备升级。

候补沿用自身默认战术/专修/道具/装备；不同职业之间并非完全相同装备。换人保留其余角色，随后按职业应用职责分工。所以阵容对照包含身份、默认配置、辅助覆盖和输出结构共同变化，不能将差异单独归因于职业强弱。纯实验配置，不向公会发放经验或资产。
