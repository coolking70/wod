# v0.110 辅助阵位轮转

基线v109 084d653f9295fa7e77fd5c7f1e9cb8048616b70f，分支feature/v110-support-priority。继续已确认的战前配置、自动整段远征与自由普通技能；永久补给未实施。

## 新的实际选择

正面阵位辅助可以明确选择“按辅助阵位优先”，按个人supportOrder完整五阵位顺序寻找尚未获得该技能效果的存活友方。先过滤同名效果，再按本次人数上限选取第一组；不会跨阵位填满人数。一次覆盖3人后，同阵位第4名未覆盖成员可以在下一次单独付款施放，再转向其他阵位。效果结束后从优先顺序最前重新检查。

同技能的任何现存组件都会阻止重复覆盖，含等待生效的护印/缓释；其他技能互不冒充同名效果。另一名施法者会看到前序队员真正施放的结果，再决定是否转位。援护另排除施法者本人；净化、召回、自身、全队辅助、召唤和自动治疗保持原目标规则。每次仍需完整技能费用并占一次预备行动，持续时间、媒介、材料底线、窗口和本房一次规则不变，不能保证整场持续覆盖。

默认不启用：指定阵位或自身的旧指令保持原行为，即使只保存一个supportOrder也不会改变战斗。设置按房间覆盖，无覆盖的下一房恢复个人默认；可恢复继承。编辑器、静态部署/伙伴/公会核对、真实候选与支付证据、配置差异、同职业历史战术复用、命名方案/路线绑定和整档均贯通。静态候选只表示初次状态，不把其当作后续已实现的整场覆盖。
