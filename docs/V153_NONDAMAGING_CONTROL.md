# v153 · 无伤削弱与普通嘲讽

本轮补齐可被防御的攻击不必造成生命伤害这一基础机制，而非再换一种伤害颜色。吟游者普通技能「讥潮短句」使用乐器、4MP、无材料，沿既有魅力/意志与心理攻防；命中附「动摇」，当前与下一回合的后续攻击均值−12。不掷伤害、不扣生命，不套护甲或伤害抗性；命中级别不放大固定削弱。防御仍真实支付，闪避仍消耗本次施法与普通行动，不附状态。不是强制换目标、沉默、取消行动或事后撤销伤害。

新字段`nonDamaging`在现有攻击结算中先完成攻击、防御及其支付，然后记录独立control事件，跳过伤害随机、伤害统计、倒下和生命转态。效果只参与攻击均值，不降低攻击技能等级，因此也不降低该技能的伤害基值。治疗、支援、防御和先攻不受影响；旧挫志仍按原技能等级规则影响命中与伤害，两者不是同一个状态。已有动摇者和心理类型免疫者先排除，无候选免费查后备；可选中其他阵位仍沿原攻击目标路线，不擅自锁定阵位。自动应急不代选无伤削弱，需明确配入普通指令，避免把进攻后备改成自动控制。

动摇不叠加、不刷新；来源倒下仍保留，目标普通行动照常，可在下一预备阶段净化。到期后可重新命中并建立新的效果ID；房间结束沿原清理。普通培养仍20/40/60XP三级，可同时培养其他普通技能、精确退款，不需课程或独立后期进阶；只提高攻击命中，不增削弱值或期限。准备、实装核对、正式出征、历史、个人摘要、阶段图形、来源追溯和整档恢复贯通。战报明确标为动摇/抵抗，生命前后值保持，不显示为“吸收”或虚假的生命伤害。
