## 玩家如何使用

在现有伙伴职责选择中，将维斯或候补米菈设为“截疗学者”，先预览实际装备、训练和逐房指令，再应用。职责使用原有法器、专修截疗符，预备为前排屏障；普通指令先找存活治疗施法者施放截疗符，条件不满足则用微光。未选择该职责时，既有默认方案不改变。

也可在战前编辑器为学者手动配置该技能及目标。它是两名学者的可选基础技能，不新增成长阶段或解锁费用。伙伴托管使用公会实际资产；职责不会购买装备、支付训练、发放经验或改造装备。实验构筑的训练建议不等于公会已经拥有训练。本轮正常新公会实测维斯训练为空，核对显示0/6点，仍可凭基础技能及专修施法。

## 规则与取舍

| 项目 | 实际行为 |
|---|---|
| 施放 | 单体法术攻击，智力/意志，需法器；6法力、1符纸；伤害系数0.65，低于微光的1.0 |
| 附着 | 命中仍存活且拥有草药救护技能的目标后附着禁疗；闪避、击倒或无该能力不附着 |
| 零伤害 | 命中而伤害被护甲吸收，仍可附着；使用既有法术命中检定，无额外控制抵抗随机检定 |
| 生效窗口 | 限制本回合余下的自动草药救护，回合结束消失；已完成的治疗不撤销 |
| 被阻者 | 到达救护检查且有合格伤员时记录受阻，救护不扣法力/药草、不占行动，继续普通指令 |
| 不受影响 | 普通指令、优先使用法力瓶或自用救急药匣照常；未开救护、无伤员或未达阈值不伪造受阻 |
| 重复命中 | 同回合不叠加、不延长、不替换首次来源；每次攻击仍照常付费并结算伤害 |
| 资源与双方 | 遵守现有港口符纸预留；敌方同规则、用敌方耗材，不扣玩家符纸。现有关卡敌人未自动获赠该技能 |

出手晚于药师时，可能只付攻击成本而没有治疗可阻；先攻辅助与目标职责因此有实际意义。禁疗命中不阻止敌人攻击，选择它也要承担较低伤害、法力和符纸竞争，以及专修不再投给屏障的取舍。没有根据单次成功加数值或将候补包装为默认升级。

## 从战报解释结果

复用既有战场和治疗决策：有害状态显示“禁疗”和“受影响者”，与正面增益分开；命中附着次数和真正出现的救护受阻次数独立统计。受阻记录保留精确效果ID、施法者和受影响者，能跳到原始命中、返回原普通行动，再定位原房间调整截疗指令。

改配会载入准备草稿并冻结A，供已有A/B实验比较，不改写公会待结算快照或资产。托管伙伴仍按已应用职责执行，界面提示核对实际指令；草稿编辑不是永久改写托管职责。原“中断”统计是自己的救护占用行动，界面改称“救护占行动”，其原始统计口径不变。

附着不等于成功阻止一次救护，受阻次数也不等于阻止的治疗量、额外伤害或通关贡献。未做移除技能后的反事实收益计算。没有增加设置面板、推荐评分、敌群、地城、装备、奖励或在线服务。
