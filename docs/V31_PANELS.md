# v0.31 公会整备面板

将公会长页拆为出征准备、角色成长、装备与仓库、履历与备份四个面板。固定面板导航，队员选择在成长、装备和分配之间共享。准备页的公会出征入口直接打开出征核对。

待结算区域在所有面板可见；领取装备奖励后打开装备面板，否则打开成长面板。个人装备默认只显示已持有装备，可切到商店可购买或全部可用。购买、换装和分配均显示局部反馈。

当前面板、队员、房间核对范围和装备筛选保存在本标签页 sessionStorage。刷新后恢复；路线改变时不适用的房间范围回到默认。存储不可用时仍可在本次页面内使用。没有修改战斗规则、经济、存档结构或增加旧档迁移。

## 验收

- JavaScript 语法检查通过。
- 浏览器验证四个面板切换及非当前面板隐藏。
- 待结算远征在装备面板可领取，领取后仓库数量从3变为4。
- 装备选择伊芙后，成长面板仍对应潮术师；刷新恢复面板与队员。
- 房间核对 cistern 跨面板及刷新保留。
- 默认已持有仅显示仪式法器；商店列出未持有普通装备。
- 购买护印长袍后金币770→710，立即装备；已持有筛选显示原仪式法器及新长袍，并有成功反馈。
- 履历面板展示六次测试远征与备份入口。

以上使用本地预览的测试公会，不涉及线上玩家存档。规则测试沿用 v0.30 的188项通过基线；本轮未重跑全量规则测试。
