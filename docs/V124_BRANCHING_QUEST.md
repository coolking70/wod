# v0.124 单人分支任务：归信航程

## 玩法与动机

v123的真实队伍有多次邮路止步与一次通关，但近期路线分散，既有三段故事主要检查已有成果。新任务给当前探索一条可以亲自接取、依次选路、失败后培养再继续的有限航程。它不新增战斗技能、敌人数值或永久补给，也不把前段完成变成终场减益。

在地图“归信航程”进入任务，选择本人后可免费接取。任务只记录接取时`g.next`及之后的正常远征：

|段落|当前可选通路|取得路签条件|
|---|---|---|
|岸路|错拍回廊 / 潮闸机廊|选定其中一路后，正常通关并领取结算|
|渡海接应|潮堤接应 / 潮影墓廊|第一段完成后再选其中一路，正常通关并领取|
|回邮台|沉船邮路|前两段完成后确认末段，正常通关并领取|

前两段各走一条，未走分支不算完成，也不阻止以后自由探索。当前未完成通路在无待领取远征时可改选；已完成路签固定。玩家可以暂停任务去别处成长，失败可领已过房间普通收益，路签与当前选择保留。没有失败重置、期限、入场费、额外通路费或材料返还。

正常通关但尚未领取时不进度；未接取、未选择、未来段、其他路线的通关不回填。实验、候补/培养试演、历史与收藏回看不推进。旧版rewardVersion1不计任务。本人和伙伴名册仍可切换，每份路签保存当时实际方案与本人视角，不锁定主角。

三段路签齐全后仍须亲自三选一交付：**一次40金币＋回邮铜铃/定心缎带/守望徽记之一**，无额外经验，沿既有故事奖励量级。都为已有遗物，属性与普通来源不变，未选来源明确关闭。装备入仓后手动分配，交付不自动换装；已完成任务不能重接、换结局或再次领奖。普通每趟战利品独立结算。

## 实现与存档

可选`g.postQuest={version:1,startedAt,selected,steps,ending}`，未接取公会不新增字段，不需要旧档迁移。最多3份路签，各含正常id/route/config/command，方案最多100000字符，编号从接取点起严格递增且不能占用pending；路线与段落、方案及保留履历相互核对，通关计数必须存在。路签不会随最近20条履历滚出而消失；它保存方案/来源，**不宣称保存当年的完整事件**，关键报告仍须主动收藏。

新增`expedition-post-quest.mjs`状态/进度和`expedition-post-quest-view.mjs`任务页面，只有guild正常claim(version2)调用记录。接取、改选与交付沿现有editable与存储CAS；准备入口核对公会和配置两份原始存储，跨页变化不覆盖。地图、营地、任务手记及遗物来源接入，活动任务优先提示当前通路；pending仍优先回收。准备复用路线绑定命名方案和当前种子，正式出征仍按当前真实资产与正常编号。

任务随单公会/整档备份保存，沿现有内层压缩收藏校验与四键事务。数据只新增可选字段，不改变引擎、原有战报/战利品/训练费用、26路线40装备78目标或规则标识。所有剧情、节点/条件、交付选择与40金币均为项目原创暂定设计。

三路签为23机廊、24潮堤、27邮路，未走回廊/墓廊不回填。手动选择“为没有写完的名字留白”，另得40金币与定心缎带至2725；不加XP，再手动分给本人E，旧分诊铜签仍个人持有。五次普通收益让每位出战者+180XP，训练实际总380XP（B100、C120、E40、F120）。职责、仓库原件、寻物目标和四份收藏保留；新通关铜铃仍正常入仓。最终next28，履历27..8；旧8..22精确保持。

另有四组固定分支组合只核验前两段在当前实际资产、正常seed23/24下可完成，全部通过；不代表任意队伍/种子均可达终局。专项还以20次正常后续侧廊验证路签持久化，并核验中途切本人保留各自视角，都是独立验证，不混入上述真实五次主线。

## 原版依据与边界

官方[Quests索引](https://world-of-dungeons.de/ency/Quest)描述由串联地城讲述连续故事、途中选择下一地城、可能不走全部支路，成功完成后通常不可重复；本次全文打开HTTP502，未重试。历史[Dungeon Guide](https://world-of-dungeons.net/ency/Dungeon_Guide)与[First Steps](https://world-of-dungeons.net/ency/First_Steps)公开索引支持系列地城任务与任务奖励方向，既有失败正文不再访问。

这里只以公开索引作方向依据；没有核实当前服务器等级窗口、投票/队长权限、失败/改路政策、任务道具、具体奖励或补给规则。本项目是单人托管队伍，因此没有上线账号、投票、服务器日程或等级限制。免费接取、按本次正常领取记录、当前段可改选、失败保留与奖励数值都是明确的原创改编。
