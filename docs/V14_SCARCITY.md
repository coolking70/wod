# v0.14 断潮封库

新增独立scarcity路线，原封库、基线、潮汐异变的敌人与玩法数值保持不变。新配置版本0.14；0.12及更早支持的配置自动迁移，不改路线、补给或事件选择。

## 挑战规则

- 战前共享补给总预算24，预设8药草/8符纸/8箭矢。途中所得不受携带预算限制。
- 每房5回合内清场，第5回合完成算通过，结束仍有敌人则封路，即使队员存活也失败。
- 本路线拾取药草占用第二房间1回合，限时为4，仍获得2药草。不跳过某个角色的行动，不抽额外随机数。
- 赶路与救治不额外减时，救治仍按既有3药草检定规则；沉钟与末房分支保持原规则。
- 全部敌人直接使用封库模板，无隐性血量、伤害加成。

切换到挑战时若当前补给超过24，界面拒绝切换并提示手动调整或载入预设，不截断物资、不保存非法配置。挑战页、事件选项、进场记录、回合显示、房间结果与失败复盘都说明限时及代价。

## 样本与发现

scripts/sample-v14.mjs生成dist/samples-v14.json。种子1–32，三种构筑×三救援×三沉钟，共864次。默认均衡、按房间应对、药师专精均携带相同8/8/8；按房间应对改变射手和潮术师第二/三房的普通指令，药师专精改变药师治疗训练和专修。不是单变量构筑归因，也不是当前编辑配置预测。
