# v0.162 闸桥通行

既有技能培养终于有开战前的用途：首房可预选专业拆闸、强行开闸或直接战斗。第二房仍须正常战斗，跨房带着真实生命、法力、道具和共享物资。不是给角色新增一条必学技能，也不改变普通技能自由搭配。

## 可复现规则与边界

两房30补给，首房难度70。专业拆闸用射手既有机巧拆解，强行开闸用守卫既有盾击，费用由原commandCost读取；当前两者均3法力、无共享材料。在进场事件之后、回复/预备/先攻之前检查一次，按实际同行者的职业、已掌握等级、装备、存活与可支付性选均值最高者，同值按队伍顺序。候选与等级来源写入报告。

实掷为floor(均值×(0.5+(两次独立随机数之和)/2))，达到70成功；单独派生的种子流不影响原战斗掷值序列。成功、失败都支付原费用；无合格者免费进入原战斗，直接战斗不检定不收费。专业检定不占普通行动，没有额外属性伤害、补给、经验或奖励。成功保留全部原守军生命，以bypassed标识退出交战，首房0战斗回合；不是投降或击倒。失败按原敌情战斗，不退费。只接受单波、不混坚守/投降的模板；输出退出标识不能由玩家或敌方模板预设。

准备页可切换并撤销策略，公会出发核对使用真实培养和装备。原事件可追查，战场和冻结阅读器显示“已绕过，未交战”。法力去向单列进场专业检定，队员账本将该支出与施法分开。完成目标采用公开通行条件，不把绕过说成肃清。
