# v0.37 个人英雄与伙伴职责

用户确认采用个人英雄＋托管伙伴。新增公会默认主页，从六位现有英雄中选择主角，显示其成长阶段、经验与装备，提供个人成长、装备和战术入口。暂不增加角色创建或新职业。

伙伴可选择两套既有职责或自定义指令。职责持久化到公会备份，在公会出征配置生成时应用；出征核对与公会模式历史比较使用相同投影。托管覆盖专修、预备、普通和预设提供的治疗设置，清除对应逐房指令覆盖，保留站位、防御、道具、装备与永久训练。不会自动购买、训练或提升数值。实验试跑仍使用准备页草稿，不受公会职责自动接管。

选择主角不转移资产。初次伙伴保留自定义战术；切换主角时新主角解除托管，原主角变为自定义伙伴。高级编辑伙伴、加入进阶指令会切回自定义，避免改动被预设覆盖。未结算期间不允许更改主角或职责。

验证：204/204自动测试通过；新增主角与伙伴权限、实际资产保持、核对/出征一致性、草稿恢复、结算期间保护、无效职责拒绝测试。浏览器验证伊芙主角、莱恩支援猎手、刷新保存、主角成长定位、自定义编辑回退；第9次测试远征通过3场，领取150金币/每人70经验和沉钟残片。

本版托管是确定性战术预设，不是在线玩家或生成式AI决策。伙伴装备与成长仍由玩家管理。无旧存档兼容开发。

后续沿已确认方向推进：个人战后贡献与资源消耗反馈、伙伴职责目标预览，再扩展个人职业成长与创建角色。需避免将贡献简化为单一伤害排名。
