# 下一阶段：新章节的路线选择发生在何时

固定属性配装阶段完成，下一阶段建议制作一条原创第二章路线，用不同伤害类型、支援组合和事件来检验队伍与装备取舍，并同步制作场景与事件CG。先确定交互方式，避免把自动远征直接扩成另一种玩法。

## A 出发前策略，全程自动结算（推荐）

沿用WoD式完整远征。出发前选择路线偏好和事件策略（如药草不足时绕行、携带法器者尝试解封）；实际队伍状态和检定决定分支。战斗中及房间间不暂停换装、换人、重配战术。通过有条件的遭遇和事件节点增加变化，记录选择原因与后果，回营复盘再调整。

实现：声明式节点图、有限条件、事件结果与节点访问记录、分支敌情预览、整段确定性战报。预生成场景/CG按实际访问节点播放，不改规则。保留一次出征/一次结算/一次历史快照的数据边界。

## B 房间间手动决策

每场结束后暂停，查看当前伤势和补给，决定下一条路线或撤退；首版仍不在战斗中手动下指令。是否允许营地外换装、消费补给另行限定，不默认开放无限调整。

实现：持久化进行中的队伍、随机流、节点位置、事件、资源与结算状态；分段恢复与防止重复结算；记录玩家选择以重演。这会改变当前整段一次模拟的核心结构，操作频率和玩法更接近逐节点探险。

## 为什么在这里停

两者决定第二章节点、战报、存档和玩家操作时机。先前已确认的个人英雄、托管伙伴、招募名册、固定属性配装都保持。推荐A，因为它继续加强战前构筑和团队协作，且用户此前强调原版WoD的特色。原讨论时仅准备方案；当前第二章自动模式已经实现，未引入手动停驻。
