# v0.27 地下城奖励与战利品

固定公会路线继续推进：八条路线拥有明确的通关奖励，其中引导路线无装备，其余通关必得一件。六件地下城专属装备采用固定属性与取舍；当前没有随机词缀、稀有度或技能解锁。

## 奖励
基础每通过一场20金币、全员各10经验。失败仅得已通过场次基础收益，不掉装备、不计首通。

首次通关固定装备，重复通关按路线、种子和远征序号确定池中一件；独立于战斗随机流，不影响战报。当前没有保底或重复保护。

## 仓库与装备
领取结算时装备进入公会仓库。选择队员后比较相对于当前装备的护甲和属性差额；分配消耗1件并立即装备，旧装备保留在个人库。已拥有者不能再次分配同种物品，可给其他队员或将未分配装备以20金币出售。商店不能购买地下城专属装备；实验模式仍可自由使用。

新装备兼容已有盾甲/弓具/法器类型判定，沿用原有属性计算；没有改动原装备和战斗公式。

## 兼容
公会存档版本2，原localStorage键保留。版本1只补充空仓库和空通关记录，不改变既有金币、经验、装备与训练。首通从本版开始统计，不追溯历史。版本1未领取远征标记rewardVersion=1，仍按原金币/经验规则结算，不发新装备。新远征快照标记rewardVersion=2。未知版本拒绝导入，不覆盖原存档。

仍是本机前端存档，没有跨设备同步、服务端资产权威或多人交易。
