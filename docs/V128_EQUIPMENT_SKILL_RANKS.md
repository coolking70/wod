# v0.128 装备技能等级与永久培养

此前固定装备只提供属性/护甲/抗性；战斗里的技能等级来自基础、专修、永久培养和攻击类临时增益。本阶段补齐**按当前穿戴提供特定技能/防御等级**，让配装与经验投入成为两个明确来源。没有新增技能、路线、货币、装备槽或永久材料经济。

## 两件有取舍的普通装备

沿用现有商店每件60金币、首次购买归个人持有、以后免费换装的规则，不生成随机词缀。

|装备|部位/类别|固定属性|特定等级|
|---|---|---|---|
|守潮札册 wardfolio|武器/法器|智力+1、意志+1、敏捷-2，护甲0|潮纹屏障+3、断流符+1、心智抵抗+1|
|防水药签 medicbadge|饰品|意志+1、敏捷-2、体质-1，护甲0、法术抗性-10个百分点|草药救护+2、同位合剂+1|

并非统一升级。真实D从仪式法器换札册，屏障10→13、断流7→8、心智抵抗9→10，但法力上限72→69且先攻属性下降。真实F从铜签换药签，救护12→14、群救6→7、生命102→106，但法力70→68、失去铜签的远程抗性且更慢。属性与技能等级共同影响检定/效果，整数取整与固定效果意味着每次换装未必提高实际治疗或屏障。

## 结算与资产边界

- 只有本人当前三槽ID提供等级，个人库存、仓库、其他人及保存未应用的配装不计；换下即时移除，不是可破除技能增益。
- `unit.skills`仍保存基础/专修/永久培养形成的原始值；`skillLevel/skillBreakdown`按已有技能再加装备一次，临时攻击增益另计。救护、群救、辅助、攻击、事件和试演统一使用实际等级。
- 防御等级只在本次实际选择对应防御且条件满足时使用。缺蓝回退自然防御不享受心智抵抗+1，仍按原条件与费用；不额外授予防御行动或减费。
- 装备不授予本职业没有的技能，也不替代课程学习；等级不计永久培养上限、累计经验、成长阶段或退款；原版精通仍未完整标定，本阶段未扩展。最高+3仍是永久培养上限，F永久救护3加装备2可得到出发总等级14，仍不能培养第4级。
- D退回实际培养的屏障1只返20XP；札册+3不会变成可退款投入。换下札册后当前屏障12→9，札册仍个人持有/保存也不生效。F救护第3级重修仍按真实60XP退款/重学，不按总等级14计算费用。
- `equipmentTotals`仅在穿戴含等级装备时新增ranks字段，旧装备返回结构保持。战报施法和防御保存独立装备来源；单位检查器读取当次`report.config`，不读现在公会装备。新完整报告可冻结，旧冻结payload不重写。

装备卡/同槽差值、实验编辑、实际成长与出征、培养试演、回放单位与当次施放来源贯通。只读试演显示装备在内的13→12真实静态差别，不支付经验或发奖；实际资产仍覆盖实验装备/培养。
