# v0.127 断流：法力作为进攻目标

v126灯桥实玩持续面对救护/施法压力；原本只能清除生命、截疗、拆增益，不能主动消耗敌方法力。本阶段加入MP伤害机制和学者自由普通技能「断流符」，复用已有路线验证新的分工，未增加路线、装备、货币或永久补给。

## 规则与真实代价

断流需法器，消耗6法力及1符纸，使用一次普通行动；智力/意志、技能等级、法术攻防与当时法术抗性参与，威力1.1。它只削减MP，不造成HP伤害，不给施放者回蓝，也不附着可净化状态。原版有法力伤害方向，但本项目沿既有法术通道简化，未新增独立伤害抗性表。

1. 先排除机关、法术免疫及MP不大于0的敌人，再沿原阵位/职责/优先顺序选择，支持逐房、一次/每回合一次、媒介、材料留存和普通后备。
2. 空候选免费后备，不支付、不标记本房一次成功或消耗额外战斗随机；游标规则保持。选中并施放后照常支付，闪避不退款。
3. 目标先支付本次实际防御费用；再计算 `floor(削减投点×命中倍率×(1−法术抗性/100))`，按防御支付后的剩余MP截断，不使用物理护甲。目标防御用尽法力时，断流可实际削减0，但本次支付仍保留。
4. 不取消已排定行动、召唤或已完成治疗，不把MP归零当倒下。之后仍检查费用，低耗后备、道具和借潮咏照常；**存活者原有每回合自然恢复1法力不变**，所以不是永久封魔。既有缺蓝技能仍可能回退自然防御，心理/法术仍沿原防御栏。

普通技能自由搭配，与课程和独立进阶分开，米菈同职业也可使用；未自动为任何人选择进阶或修改原技能参数。真实公会训练最高+3，沿现有20/40/60经验与精确重修。实验草稿不能授予公会实际等级，pending/多页面保护保持。

## 战报事实分账

`expedition-mana-damage.mjs`提供资格、MP截断和规则视图；engine在原攻防后发出独立`mana-damage`事件。个人统计和账本分别记录削减敌方/本人被削减，生命实伤/承伤与自愿施法/防御费用不混加。每次记录MP前后、计算量/实际量/截断、HP不变、防御支付和法术抗性。

行动摘要、精选、逐条诊断、MP动画、个人代表记录和原始计算贯通；来源不推算取消了多少行动或治疗。完整报告保留在正常出征/历史/冻结收藏与整档备份中，回放只读，不重新发奖。旧冻结报告保持原始字节数据，不用当前技能清单改写。
