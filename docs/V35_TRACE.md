# v0.35 检定支援溯源

施放与攻击下展示当时已生效的效果，区分施放者与防御者。显示攻击/防御均值、实掷、等级和实扣生命；从效果可跳转唯一施放记录，并返回原检定。

事件来源新增 effectId 与 component，效果施放记录附带同一 effectId。按标识、施放者、目标与先后关系定位，不按同名或同数值猜测。未定位来源仅显示文本。没有新增存档迁移。

来源列表描述当时生效状态，不声称每项都参与本次公式；例如攻击者身上的护甲增益也会展示，但不作为额外攻击伤害。没有改动随机数、资源、战斗公式或奖励。
