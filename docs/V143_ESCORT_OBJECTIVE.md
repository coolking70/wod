# v0.143 退潮护送

补“清光敌人之外，要保护谁”的单人目标。退潮护送是两场独立路线，伤员引航员奈芮固定后排90生命，随六人穿过断缆栈桥与救援船台。NPC不是第七名队员，不能选为本人、招募、穿装或分经验；不出手、不掷先攻，不消耗先攻随机数。双方仍可按原范围选中它，治疗、护印和援护真实生效并支付原费用。它的自然防御仍独立检定。

所有覆盖上限照旧：全体最多6人的技能可能不覆盖第七位对象；位置最多3人也会因正式队员站位而改变候选，双守卫同技能不叠加。原六位正式队员仍是预备顺序、普通出手、成长、死亡阈值与结算统计的主体，不能靠只剩NPC继续远征。伤员状态在场上另标“护送对象”，回放HUD按当前快照显示；点击可看受击和药师救护时序。

伤员生命跨两房继承，不在房门回满；房间/远征效果按原范围结束或保留。任一伤员倒下使本次护送停止，即使六人还活着，或同一次完整施放中也消灭了敌人。当前一次完整施放先结算全部实际目标，不截断群攻或退还费用；不继续后续队列。只有本房守军全部清除且伤员存活才算完成本房。普通失败只给此前已完成房间的20金/10XP，不给通关/首通/攻略首证，不产生额外扣款、永久伤势或永久补给。下一次是重新开始的新护送。

两房30份携带预算，默认12草/10符/8箭。每房敌情完全公开：前线拦路卫、后排齐射弩手；后房卫士先用守势。路线普通通关额外60金/25XP，首通再40金/10XP，无新装备或道具。这些敌人数值、NPC属性和规则均在结果前冻结，未为测试胜负调整。目录增加为30路线/90攻略目标，装备45、职业6/名册9、开局六人不变。旧精确目录断言更新为30/90，完成条数、旧首证、报告和边界不放宽。
