# v0.67：历史单人战术的明确预览与复用

2026-11-05。从v0.66 dd3bcc9、433测试继续，本地分支feature/v067-personal-tactic-reuse。

历史对照新增“复用历史单人战术”：先选择历史队员和当前同职业出战目标，列出目标当前实际配置与将采用字段；只有明确应用后才改变准备方案。保留目标的身份、实际装备、随身道具种类、永久培养、后期进阶、个人经验与公会资产。其他队员实际战术、当前路线、种子、共享物资和队伍顺序不从历史继承。

复制的个人战术字段为站位、技能/属性/防御专修、防御选择、道具使用策略、救护策略、预备和普通指令。托管伙伴会明确切到自定义，并定位该目标编辑器；原管理模式可在伙伴面板重新选择。已有配置撤销只撤销方案载入，不等于回滚公会职责事务，不能称为完整事务撤回。

## 范围、课程与过期保护

默认只复制默认战术并保留目标当前实际逐房覆盖。同路线可勾选复制两份路线示意所涉及的房间范围：该范围内未在历史设置的覆盖清除，其他当前预留房间槽保留；历史中的额外预留槽不复制并提示。跨路线逐房选项停用，后端强行请求也拒绝，不因房间槽ID重用误套别的路线策略。

预览与应用共用校验：职业必须相同、目标必须出战、课程必须已学、待结算禁止应用。预览快照覆盖历史来源、当前目标、出战名单、职责、pending及准备配置；过期必须重新预览。后端重新计算，不信任传入的候选公会/配置；失败不改变资产或留半完成职责。装备条件等仍按当前资产提醒，不因历史用过就购买或授予。

补齐通用configurationChanges：差异包括合法但未列入当前路线示意的roomOrders/角色覆盖，标注“其他房间槽”，不表示本次会执行。比较器复制标签数组后追加，不得修改引擎静态房间列表。旧v33只断言一个站位变化而忽略另一合法覆盖，已改为精确核对两项完整标签及前后值，没有弱化断言。
