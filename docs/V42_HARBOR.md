# v0.41–0.42 盐风港：自动分支与可规划奖励

用户选择A并授权常规推荐自主推进。本次连续完成新章节、事件表现、战报因果和常驻委托两个阶段。

## 玩法

每次四场：盐风关卡 → 栈桥或暗渠 → 机房、药仓或巡道 → 无光灯塔。七个可能节点，战前预设通路及事件政策，抵达时读取真实生命、存活者、装备抗性与共享补给。没有中途手动改配。第二、三场使用分支槽统一逐房战术，当前不按每个候选节点分别配置。

自动通路：生命比例低于65%或药草少于4走栈桥；否则至少3名存活者法术抗性≥15%走暗渠，其余栈桥。这是透明启发式，不是最优解求解器。

自动事件：药草少于6打捞，否则解封。打捞+4药草并增加敌人，不治疗或复活。解封需2符纸、存活且携法器并掌握屏障或微光者；取实际均值最高人选，floor(mean*(0.5+(r1+r2)/2))≥65成功。失败照付；缺执行者/物资无消耗绕行。成功将末场核心法术10→7。分支事件在进场、战斗前结算。

## 可核查战报与表现

分支写入战报：策略、状态、执行者、均值、随机因子、难度、资源前后与结果。末场引用第三场原事件；回放只读，不重投、不再次扣费。路线证据按当前播放位置显示。普通进场快照先于分支资源变动，账本不会漏掉解封消耗。

两张AI生成静态场景：盐风港环境、潮锁机房事件。战斗仍采用可回放战术舞台与行动连接，不是实时生成的视频战斗。图像只作示意，结果来自确定性引擎。新增港口敌人的职业标识读取实际模板。

## 公会闭环

每次通关+1海图；首次六人归航额外+1海图/40金币；解封后通关、药仓后通关各首次+40金币。2海图指定兑换引灯仪杖、盐风哨衣或归航罗盘，先入仓库再分配。三件固定属性包含取舍而非随机词缀。原通关掉落仍在，首通固定仪杖。

奖励只在一次结算领取。待结算锁定兑换，重复点击、刷新、历史重演不会重复发放。公会存档升至6；按用户要求不迁移旧版。配置/基础规则协议保留0.40标识，界面内容版本0.42；旧路线规则未改，新港口配置增加harbor字段。

## 验证与限制

239项测试通过；新增13项覆盖分支条件、缺资源/执行者、招募角色、成功/失败后果、确定性、资源账本、实际房间、回放前缀、一次性结算、兑换、损坏存档与历史只读。浏览器验证策略编辑、完整四场六人归航、失败解封37/65扣2符纸、热更新恢复待结算、285金币/每人100经验/2海图/仪杖到账及兑换。

192次样本：3通路×4事件×2装备样本×8种子；全部通关且六人生还。抗性样本为c/d/e携盐晶护符的实验对照，不表示新公会拥有这些装备。自适应普通配装走栈桥，抗性配装走暗渠；各解封组8次有4次成功。不同方案剩余生命、回合数和补给有差异。样本只是诊断，当前普通章节偏宽松，不能据此声称难度或装备收益已平衡。下一步先加强挑战目标与策略价值评估，再扩内容；无需为此新增用户决策。
