# v0.44：远征用料策略

沿用已确认的战前配置、整段自动结算。把 v0.43 实测发现的“前两场用尽符纸，第三场无法解封”变成可配置的取舍。

## 规则与反馈

- 盐风港新增可选策略“为第三场预留2符纸”，默认不预留。仅在任务为尝试解封或自适应时生效。
- 前两场中，队伍耗符技能若会使库存低于2，则跳过该条指令并尝试下一条；包含准备技能。不会扣法力、材料，也不增加库存。库存为零仍报告耗材耗尽。
- 第三场事件前解除限制；解封照常消耗2符纸并进行原有检定。库存不足或缺少合适角色仍可能绕行，解封仍可能失败。
- 战报保留预留原因、库存、同一次行动实际后备结果。没有可用后备时，区分普通行动空过与没有准备施法。单次跳过不等于整次行动空过。
- 回放保留预留跳过节点，当前步骤不提前展示后续施法；完整复盘可定位首次跳过及行动证据。
- 出征核对、方案差异、A/B对照和历史配置包含预留策略。A/B港口路线显示实际经过的房间。
- 复盘的跳过数按尝试计，同一行动可有多条；不将其当作省下的符纸数量。无新增奖励或存档结构。
