# v0.122 潮闸机廊：拆解与保护

从v121真实1920金币、本人塞恩、next19继续。新增可拆解的地城机关，使射手在输出生物与拆除持续威胁之间分配普通行动，队友承担清场、屏障和援护。不是新增陪练变体，也不改变补给经济。

## 机关与拆解

遭遇模板可显式声明固定`mechanism:true`，使用既有HP字段记录耐久。本文“生物”泛指非机关战斗单位，含亡灵和普通召唤物，不根据名称推断类别。普通攻击不选择机关；射手自由普通技能“机巧拆解”只选择机关，不攻击生物。先按类别筛选，再按固有类型免疫、既有阵位/职责/优先顺序/人数选取。这是对象类别，不是“免疫四种伤害”或可驱散效果。

拆解占原普通行动、3法力、无共享材料，感知/灵巧、原技能等级/专修/培养和临时攻击技能增益参与原检定。暂借现有远程攻击、防御、护甲与抗性流程，基础强度1.2；没有引入原版独立拆阱攻击/防御类型、工具装备槽或未经核实的等级门槛。拆解不触发物理援护，也不会被守卫接到生物身上。没有合法机关则免费查后备，不额外抽随机、扣资源或占行动。

沿用原游标与once/round规则：免费失败不消耗本房一次，增援不会重置游标；轮转后备可回查，持续后备仍有合法目标时会继续它。后备本身失去目标时仍按原失败查找循环尝试其他条目，不误称永远不能回查。

机关不能接受普通治疗、同位合剂、友方增益/辅助轮转或法力援助。耐久归零后按原存活检查停止以后尚未执行的行动，只记录一次“已拆除”；已发生的攻击/支付保留，既有附着状态不会因来源倒下自动撤销。普通召唤物不继承主人的机关类别。玩家配置不能自行声明该类别，所有公开增援模板也执行类别校验。

实际耐久损耗仍计入原本人实伤，额外`mechanismDamage`仅说明其中的拆解部分，不能重复相加、当作对生物的伤害或换算避免的攻击。专用证据、单位耐久、停机提示、个人表现和默认/精华回放均使用实际记录；免费类别检查可跳到首个真实后备再返回。

## 可玩内容和实际配置

两房30携带预算，沿正常出征/领取模型：首通140金币/每人60XP，重复90/40，无装备或额外拆解奖励。26条路线、40装备、78普通攻略目标。全部机关、耐久、技能、目标与费用在出发前公开。

| 房间 | 固定机关 | 配合问题 |
| --- | --- | --- |
| 绞线弩廊 | 前排绞线机弩，75耐久，持续齐射后排 | 射手拆机弩，其他人清巡卫/弩手；后排保护仍有价值 |
| 符压闸庭 | 左翼符压喷口，105耐久，持续潮汐冲击中央 | 射手在拆解/先打医师间取舍；队友清盾卫/后排，中央承压 |

两个可改起点只改变射手是否先打一发后排重箭。屏障按第一房后排/第二房中央配置，守卫援护后排；机关不能被敌方医师修理。“准备草稿”和“公会实际指令”分别核对逐房拆解条目，采用真实房间覆盖；托管职责把草稿拆解替换掉时会提示本房没有拆解。提示只检查配置，不保证窗口、游标、存活、法力或检定结果，也不禁止玩家有意挑战。
