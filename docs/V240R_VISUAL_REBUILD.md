这是 2026-11-18 全新独立工作区的重新实现，**不是恢复旧 v240 提交**。

## 改动
- 原创自包含海港夜色 SVG：灯塔、月亮、海面、船与营地剪影。
- 深青/暖金视觉体系，营地标题与主行动层级，主导航和九个营地面板线性图标。
- 小屏五列主导航、双列营地导航、训练面板/文件输入防溢出。
- 保留原营地金币/结算次数文案、按钮选择器、可访问名称、反馈状态。
- 不修改引擎、经济、游戏存档或单页写入协议。没有把新视觉层接入任何外部服务。

## 验证
- 全量 `node --test tests/*.test.mjs`：2181 通过，0 失败，0 跳过，约 224.5 秒。
- 使用独立证据运行 `rebuild-node-oMIYUL`，stdout、stderr、命令及运行清单保留。
- 模块语法检查、`git diff --check` 通过。
- 独立只读审查未发现阻断缺陷。
- 支持的云浏览器实测 320/390/1440 名义宽度，对应带滚动条的实际内容宽度 305/375/1425。每档九个营地面板均 `scrollWidth == clientWidth`，共 27 项。
