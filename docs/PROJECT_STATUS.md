## 已确认的开发约束

战前构筑与队伍协作优先；采用个人英雄＋托管伙伴、小规模招募、固定属性三部位装备、整段自动结算。无需旧存档兼容。常规细节按推荐自主推进；改变核心玩法、多人/账号后端、新持续费用、商业化或公开范围时才请求关键决策。详见DEVELOPMENT_POLICY.md。
