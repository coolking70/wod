## 未完成及限制

- 旧会话v0.46：原报告264项测试对应源码仍未找到。本轮已从v0.45重新实现并使用新测试/报告验收，不视为恢复旧代码。
- 候补不能当作默认升级：v0.45实验中原阵容32/32通关、第二学者替射手29/32、第二药师替吟游者0/32。它们同时改变多项配置，不能单独归因职业强弱。
- 本轮已分别验证辅助、目标、自保优先及中央/后排救护分工；所测双药师配置仍不足以推荐。第二学者本轮576次对照仍未证明稳定升级；更多成长/敌情及其他替换位置继续排期。
- v0.49的边界用例采用显式测试属性；单次正常公会疗所用于验证入口与规则。两者均不构成新技能/双学者的平衡结论。旧v0.45–v0.47候补实验没有使用截疗符。
- 用料账本的UI及分支事件对账限定港口；不能宣称覆盖全部路线收支。
- 无账号、云同步、在线多人、随机词缀系统、在线生成CG；本机存档不等同Git源码备份。
- 暂无证据能定位旧会话卡住的具体原因；旧会话只确认发布停在v0.45，其所称v0.46没有找到可恢复提交；本轮重建另有本地提交。

## 已确认的开发约束

战前构筑与队伍协作优先；采用个人英雄＋托管伙伴、小规模招募、固定属性三部位装备、整段自动结算。无需旧存档兼容。常规细节按推荐自主推进；改变核心玩法、多人/账号后端、新持续费用、商业化或公开范围时才请求关键决策。详见DEVELOPMENT_POLICY.md。
