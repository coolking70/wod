# v0.140 留蓝与队伍续航

v139正常63护库的守卫末态0MP。预备援护、守势、盾缘重击与独立格挡使用同一份个人法力，原本只能等到施法费用不足才找后备。v140让玩家为有法力费用的单条预备/普通指令设置付款后的最低余量，不改技能、装备、敌人、费用或奖励数值。

## 执行规则

高级指令编辑中的“用后保留法力”0表示关闭并删除字段；保存的`keepMana`只接受1–200整数，只允许有法力费用的预备/普通技能。200是原型输入边界，不是原版上限。默认没有该字段，旧行为不变。逐房覆盖、复制、方案册、实际公会出征核对和整档备份沿用现有指令结构。伙伴若仍由预设职责接管预备/普通指令，实际出征继续以该职责为准；本功能不自动改为自定义，须在原入口明确调整并核对实际指令。

每次实际机会先按既有模式、装备、禁疗、当前法力、材料及共享留存条件检查，再以经过独立进阶和施法媒介修正的真实费用计算`当前MP − 本次费用`。等于底线可施放；低于底线免费查后备，不付费、不掷目标/攻防/伤害、不占行动、不标记本房一次成功。后备仍按原规则支付和使用原行动机会；没有后备可能空过。换房继续检查当时余量，不补满法力。

这不是锁定资源：其他未设条件的指令、防御、付费先攻、自动救护、道具和事件保持原规则，仍可能令MP低于底线。设置过高可能压制输出或援护，不提供自动推荐。战报记录当时MP、真实费用、用后余量、底线及实际后备记录；非诊断/重点模式可见，允许跳转并返回。满足法力条件但因其他原因未施放时明确显示没有付款。

## 原版依据与改编

[官方旧百科专家配置](https://world-of-dungeons.de/ency/Konfiguration_-_Experten)的公开索引支持按序访问指令、缺法力/材料时跳过及条件治疗替换行动。本阶段没有验证当前服务器的逐条留蓝条件，`keepMana`及输入边界是项目改编。未找到足以支持新增战后休息的原版证据，未改变房间间不休息、不复活的既定规则。未加入永久补给经济。
