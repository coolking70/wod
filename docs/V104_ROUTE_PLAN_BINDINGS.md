# v0.104 路线战术分配（项目暂定）

补齐保存战术之后的使用循环：命名方案绑定到同路线，地图、营地目标和攻略目标准备时复用。地图取完整方案（含手动实验种子）；营地保留当前手动种子；攻略目标仅再覆盖明确选择的目标和当前种子。直接路线下拉仍保留当前草稿，明确的实验预设仍是工厂预设。没有绑定的路线保持原工厂行为。

更新绑定方案立即影响下次准备；已发生的正式出征和待领快照不受影响。跨路线更新绑定方案须先解除。支持删除方案并清理其绑定、腾出12个名额中的一个；产品界面删除需确认。删除/解除不改当前草稿、公会资产、本人或伙伴职责。实际装备/培养/课程仍在出征核对，不代购代训。坏绑定拒绝准备，另一页修改或存储失败拒绝覆盖。整档备份只在非空时增加可选planBindings并完整校验/恢复。

此分配方式是本项目暂定设计。尝试原版官方“分配战斗配置”“创建战术”等百科正文，当前返回403/502或工具不可访问；仅搜索标题/片段不算核实全文。失败URL、状态见云端reference-read-attempts.json；没有绕过拒绝或把原版历史数据当作现服规则。这个限制阻止声称精确原版行为，不阻止明确标注的便利实现。
