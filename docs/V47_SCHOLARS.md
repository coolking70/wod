## 游戏中的实际变化

`dist/expedition-cooperation.mjs` 的逐房协作核对现在包含**全部预备辅助**，包括屏障、延时护印、药膳、守势与吟游辅助。每条展示实际队员、配置的回合前顺序、预备指令序号、正式队员候选、单次法力/材料以及本房一次/持续检查/轮转模式。

覆盖遵循既有目标选择和上限，不把第四名中央队员算进最多三人的辅助。护印多个效果组件仍按一次成功施法计费用。这里展示的是当前输入配置的静态候选和单次费用，不预测实际施放时刻、次数、总消耗、支援强度或胜负；预留、同名效果、资源和倒下仍以战报为准。

每条辅助增加“调整某人第N条预备”入口，定位到该队员的对应房间并聚焦准确的技能字段。准备页读取草稿；公会页读取已应用伙伴职责与实际资产。公会编辑沿用v0.46的处理：先保留实际指令，再将所选伙伴切为自定义，避免切换后丢失托管设置。定位不会替玩家改技能、目标或频率，也不消费金币、经验、装备或共享库存。

不修改战斗规则、随机数、职业数值、装备、招募条件、成长门槛或存档schema；页面版本0.47，配置/规则标识仍为0.40.0。没有自动配装、自动招募、自动换人或新快捷战术。源码仍为无依赖静态网页，无构建步骤。

## 576次双学者实验

复现：`node scripts/sample-v47.mjs`。六配置 × 两训练档 × 两通路 × 种子1–24，每配置96次。均采用风暴、尝试解封、前两房预留2符纸、12药草/14符纸/10箭矢及既有职责分工。训练档为未训练，或每人当前专修+2/防御专修+2（6点）；不授予真实公会经验、装备或技能。

双学者固定米菈替换莱恩，保留其他五人；候补使用自身默认装备、道具、专修。阵容之间不是纯职业强弱对照。同阵容/训练/通路内保持装备、训练、补给、默认预备顺序及其余配置一致：

| 配置 | 唯一变量或组合 |
|---|---|
| 原阵容 | v0.45六人职责分工基线 |
| 双学者默认 | 米菈替换莱恩，仍以中央护印与原吟游目标执行 |
| 仅移分担者 | 仅将米菈四房站位移到右翼，不改技能或吟游目标 |
| 仅改吟游目标 | 仅改四房普通指令为射击治疗者→后排备用 |
| 一次护印组合 | 米菈右翼、每房中央护印一次；维斯前排屏障/第二房后排；吟游者追击治疗者 |
| 持续屏障组合 | 与一次护印组合相同，仅把米菈改为持续中央屏障 |

先用种子1–4探索；1–16结果用于选择候选。曾考虑仅移站位和一次护印作为运行版候选，**在查看17–24之前固定配置**；随后完成独立确认。确认结果未复现通关优势，于是撤回运行版快捷入口，全部配置只留在 `scripts/scholar-plans.mjs` / `scholar-cases.mjs` 作为实验。未根据确认结果继续调数值、换种子或重新选更有利组合。
