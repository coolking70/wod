# v0.6 远征复盘与方案册

2026-10-31。版本0.6.0，沿用v0.5.0战斗规则，不新增战斗数值。目标是让玩家从真实战报定位问题，再修改、保存并对照战术。

## 已交付

1. 远征复盘按实际到达的房间显示。包括正式队员倒下、空过行动、资源不足导致的指令跳过、防御回退、位置与攻击类型承伤组合、敌方多次召唤。
2. 每条观察记录事件索引。点击“定位原始事件”打开逐条诊断模式，显示对应真实记录，不重新模拟。
3. “从此战报修改”恢复该报告的完整出发配置、定位队员与房间，并把报告配置冻结为A；不自动替玩家改数值或指令。载入前的当前配置可撤销恢复。
4. 战术方案册支持12个命名方案，另存、明确更新所选方案、载入、一次撤销。所有房间覆盖与补给都进入快照。保存在当前浏览器，跨设备仍需导出配置。
5. A/B列出具体配置变化，并按房间比较回合、出房生命法力、实扣生命、道具使用与空过行动。未到达显示“未到达”，不会填0；不同远征路线拒绝比较。
6. 新增一键“资源诊断示例”：两套方案均无箭矢，B只比A多一条射手的穿石箭备用指令。

## 事实与推断的边界

提示来自确定性的事件聚合，不调用LLM，也不宣称自动找到了失败原因。建议标记为“尝试方向”。技能被跳过的次数与空过行动次数分别统计。一次群攻会产生多次目标受击，承伤次数按实际目标记录计算。

实扣生命只统计正式队员，排除召唤物和伤害溢出。出房生命与法力是累计状态，包含前面房间的影响；不能把出房差额都归因于本房间。单个种子改变行动后随机数消耗顺序也可能变化，结果不代表普遍胜率。

配置差异按默认设置和显式房间覆盖分别列出；删除覆盖会显示“继承默认”。即使显式覆盖值与当前默认相同，仍记录这一继承语义变化。

## 保存与恢复

配置版本0.3/0.4/0.5迁移到0.6，保留已有战术。方案册版本独立为1，读取时验证并迁移各条配置，拒绝无效和重复ID；坏记录不作为可执行方案。

保存写入成功后才更新方案列表。方案输入与保存内容深拷贝隔离。方案ID只承担本机记录标识，不承担安全身份用途。撤销只保留本次页面会话最近一次载入前的配置；刷新会清除撤销状态，但不会清除已保存方案。

新增检查覆盖只读与证据索引、跳过与空过区别、正式队员实扣伤害口径、未到达处理、精确差异、键顺序与继承语义、保存快照及容量、损坏记录与旧配置迁移。

## 当前限制与下一阶段

复盘只覆盖明确定义的观察项，未计算辅助覆盖率或自动生成最优战术。方案册不是云存档。未增加成长、掉落或多人系统。

下一阶段建议以此闭环为基础做构筑：有限训练点、技能等级分配、装备条件和一组可横向选择的职业技能；仍需保持每个构筑变化可在战报中解释。美术继续沿用v0.5样片，本阶段没有新增图片。
