# v0.26 固定公会长期养成

产品决策：用户选择A。角色、装备和训练跨次远征保留，当前没有永久死亡。此版实现最小成长闭环，尚无账号、云同步、等级树或随机掉落。

## 玩法与边界
- 六位常驻队员，初始穿戴原有基础装备、永久训练为零。
- 公会远征沿用准备页战术，装备/训练由公会资产快照替换，实验方案不能免费注入公会成长。预备、站位、专修、属性专长、道具选择仍自由配置。
- 每通过一场得20金币、每位队员10经验；通关另奖20金币。失败保留已通过场次收益。归营全员恢复，下次远征补给免费补齐，暂不设耐久或复活费用。
- 每项永久训练最高3级，耗20/40/60经验，总训练预算6点，沿用现有战斗/机关规则。重修全额返还经验，不重复退款。
- 所有现有装备可按每件60金币购买，归选中队员永久持有；已拥有装备免费换装。并非随机装备掉落或全队无限共享库存。
- 出征种子按序号生成；实验试跑不生成公会奖励。

## 存档与结算
独立键abbey-guild-v1。出征前先写入待结算配置快照与序号；战报从快照确定性恢复。领取时计算对应报告并在一次存储写入内增加资产、记履历、清空待结算。再次领取被拒绝。未领取不能再次出征/训练/换装。

写入失败不更新内存资产；写入前比较原始存档防止其他页面已写入后的陈旧覆盖。此比较不是跨标签页原子锁，当前前端本机模式不提供服务端反作弊、云事务或账号安全保证。导入旧备份会恢复旧进度，这是用户主动恢复行为。

支持备份导出和校验后导入；损坏存档不覆盖并可导出原始内容或恢复有效备份。旧战术配置与实验方案册保持独立。履历显示最近20次，累计次数独立保留。规则引擎及战术配置协议仍0.25.0；界面版本0.26。
