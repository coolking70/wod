# v0.40 固定属性多部位配装

2026-11-01，用户选择方案 A。已实现武器、防具、饰品三部位，27 件具名固定属性装备。无随机词缀、品质实例、强化或套装词条。

## 玩法

- 六人出战及候补分别持有装备。商店每件60金币，首次购买后个人永久持有、免费换装；仓库分配消耗一件库存。换装只替换同部位，旧件保留。暂不跨人转移已经分配的装备。
- 武器提供携盾、弓具、法器类别。防具本身不满足武器条件，例如穿铁壁重甲但拿弓，不能格挡或使用盾缘重击。全职业可穿戴，技能仍受职业与武器类别约束；基础技能沿用原有条件，不为本次额外加门槛。
- 武器槽当前包含剑盾组合，不新增副手或双持。圣匣重盾贡献2护甲/敏捷-2/意志+2，配铁壁重甲后仍是8护甲/敏捷-6/意志+2，避免把旧整套8护甲重复叠加。
- 新商店饰品：望哨镜片（感知+2、意志-2）、盐晶护符（法术抗性+20%、灵巧-2）。新掉落饰品：锚誓指环、回声耳坠、疗所护符，分别偏向承伤、施法、远程防护。全部具备明确收益和代价。
- 掉落继续独立确定性随机流、通关必得一件、首通固定池首件；新增饰品加入对应路线池，不改既有首通保证物。目录显示每件来源与首通标记。同名装备数值一致。
- 装备属性汇总进入检定、护甲、抗性；生命上限为50+4×穿戴后体质，法力上限为20+2×穿戴后智力+穿戴后意志。临时战斗增益不追溯扩容。抗性沿用-50%至75%截断、护甲后减伤，战报记录实际抗性和减免。
