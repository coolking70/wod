# v0.145 · 雾孢温径与自然耐病

本轮补体质/魅力的独立防御职责：公开敌方孢潮喷散使用疾病攻防，队员采用当前2×体质＋魅力＋全防御加成，自然耐病不付法力，也不套用心智抵抗、闪身或格挡的技能等级。屏障/守势真正覆盖者仍受益；物理援护不接疾病。没有新玩家技能、装备、收费课程或防御配置栏。

官方历史百科[标准防御](https://testwelt.world-of-dungeons.de/ency/Parade)的初次索引内容列出Krankheit为Konstitution/Charisma，并列出2×主属性＋副属性的标准均值；[属性](https://www.world-of-dungeons.de/ency/Eigenschaften)也提到体质参与耐病。直接访问前者返回403，未重试或换路径绕过；后者是历史资料，不是现行Delta认证。孢潮技能、检定随机分布、关卡、数值及费用为本项目改编。疾病伤害继续采用项目原有“非心理通道使用护甲”政策，不能把它说成已查明的原版护甲规则。

新类型不借用法术抗性，使用疾病抗性；新内容目前没有新增带疾病抗性的装备。每次群攻只付4法力/1份敌方独立药草，至多6名存活敌对单位，逐人完成攻防、护甲和生命截断。没有持续感染、额外状态跳伤、永久伤势或补给持久化；普通治疗可恢复本次损失，净化不会撤销直接伤害。
