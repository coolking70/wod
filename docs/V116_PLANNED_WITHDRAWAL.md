# v0.116 战前整队撤退计划

基线v115 `0ba4b02bf5d03a4477ca4afa17b075ba0535bf84`，分支`feature/v116-planned-withdrawal`。针对已有邮路失败中阵容瓦解后仍长时间自动作战的问题，增加可选战前结束条件；没有再增地城、技能或装备。保持23路线/40装备/69普通攻略目标、可切换本人、托管伙伴与小名册、自由普通技能和独立后期进阶。

## 玩家能决定什么

路线总览可选择“不设撤退”或存活正式队员不多于1–5人时整队撤退。默认关闭，不自动修改已有起点；开启后整段自动结算，无需中途手动干预。条件只数本次六名正式队员，不把召唤物算作留场队员，不检查实验总战力、剩余金币或永久材料。关闭时删除可选字段`withdrawAt`，没有隐含的零值政策。

每回合先照常激活延迟效果、结算缓释和持续伤害，再检查是否还有存活敌人及1–阈值名正式队员；满足才在预备、自然法力回复和先攻前撤退。不会取消上回合已经排好的行动，也不会在半次攻击中打断队列。若持续伤害先杀死最后敌人，依原条件判胜；若先全员倒下，则是全员倒下，撤退不制造生还者。不能保证触发前不会全灭，更不提供免疫或复活。

触发后本次远征结束，未清场房间不算通过；只按既有规则领取之前通过房间的20金币/每位10经验，不给通关、首通加成、遗物或普通攻略证明。已经支付的法力、道具和共享材料不退，余料不变成永久资产，也不增加跨次库存或失败惩罚。下一次出征沿既有规则重新出发，不因此生成伤势/复活费用。

## 配置、反馈与存档

设置进入公会实际出征卡、命名方案、路线绑定、导入导出、整档备份、历史配置及A/B配置差异。可以在原方案管理撤销本次修改，不撤回已赚资产。回廊与药站的可改起点沿保留种子/目标的已有方式保留这项显式计划；导入/载入完整方案仍以所载配置为准，不能悄悄继承旧撤退条件。

默认、精华和个人回放都保留整队撤退事件。证据记录阈值、实际存活正式队员姓名/生命、倒下者、仍存活敌人数与检查规则，不推算避免伤害或“少死了多少人”。个人表现提供代表记录；只切换观察者不改公会本人。复盘明确列出“按战前计划撤退”，可以回营调整或关闭，未称关闭一定能够通关。

房间记录的回合数包括已进入的撤退检查回合，因此“第11回合开始撤退”显示11回合并标明开始阶段撤退，并不是完成11轮普通行动。限时封库仍使用既有完成回合潮位，撤退没有冒充“潮水封路”；没有执行普通阶段的检查回合不额外推进一格潮位。
