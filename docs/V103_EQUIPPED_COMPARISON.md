# v0.103 把实验差异带回真实队伍

实验台新增可选“当前公会实装”依据。原准备草稿对照保持默认；实装模式对A/B都使用当次读取的当前出战六人、个人装备、永久培养、后期进阶、课程资格与已应用伙伴职责，保留各自可执行的战术、补给和分支。不会代购、代训、解锁、编队或切换职责。

界面同时展示草稿差异、实际差异及A/B各自被实装替换的项。未购买法器/未投入培养的草稿优势可能变成0项实际差异；托管职责覆盖的草稿指令也会明确体现在替换表。旧A缺少的当前成员使用其已保存个人战术，仍覆盖为本人真实资产，不带回旧队员。

双方共用B的手动实验种子，调用正式出征同一实装构成与课程校验。试演不写入正式出征或结算，正式出征仍按正常编号分配种子；不声称手动选相同种子会产生不同结果。来源标为公会实装对照且不能领奖，即使配置和种子恰与当前pending相同，也不能从试演领取。

两份结果和来源在运行时冻结。切换依据选择器不重贴旧结果标签；真实购买/培养之后，旧结果仍可读，重新运行才读取新资产。未学习课程时拒绝实装对照并清除旧结果入口，原公会与草稿保留。
