# 已确认：自由技能培养与独立后期职业进阶

2026-11-05。用户要求按World of Dungeons原版设计方向继续。普通职业技能保留自由培养和搭配，职业进阶作为独立的后期选择；不实施此前普通技能互斥方案。无需再次询问该方向。

当前项目的守护、截疗、缓释等普通技能可以同时配置和培养。既有60累计经验后付40经验学习的六职业技能属于本原型的高阶普通课程，不应称为已经实现的原版后期职业进阶。后期进阶不得通过删除普通技能或排斥普通培养组合来伪装职责差异。

分阶段处理：先提供清晰的逐级成本、实际投入及逐项可重修能力，再消除与自由培养不符的全角色固定训练点硬上限，保留经验和每项等级边界。当前项目3阶段、每项最高+3、20/40/60经验等是原型参数；它们不等于原版英雄等级/技能等级/精通表。后期独立进阶需在成长基础和内容支持就绪后接入，不能仅把当前课程改名当作完成。

原版参考依据及无法核实的部分见[WOD_DESIGN_REFERENCE_2026-11-05.md](WOD_DESIGN_REFERENCE_2026-11-05.md)。常规实现持续推进，每阶段验证并本地提交，不自动推送、合并或部署。
