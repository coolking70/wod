# v0.126 灯桥守望套装与巡行

## 装备选择的核心增量

属性培养和归信航程完成后，现有遗物只有单件固定数值，配装册只保存三部位选择。本阶段加入真正的**装备套装效果**：同一英雄实际穿戴同系列的不同部件，根据件数激活静态效果。没有新的装备槽、货币、消耗品或切换费用。

|灯桥守望部件|部位|单件固定数值|
|---|---|---|
|灯桥号琴 bridgehorn|武器，乐器类|魅力+3、意志+1、敏捷-2，护甲0|
|灯桥巡衣 bridgecoat|防具|护甲2、体质+1、智力-1|
|灯桥路签 bridgebadge|饰品|感知+2、体质-1，护甲0|

- 任意两件：法术抗性+10个百分点。
- 三件在两件效果之外另加：智力+2、远程抗性+10个百分点、心理抗性-10个百分点。
- 每档仅计一次，不按每件重复加；同一英雄当前三部位才计数。个人已持有但未穿、仓库、别的队员、保存但未应用的配装册不参与。
- 组合效果属于静态装备，不是技能增益、不占行动或材料、不能破印/净化，也不随房间到期；既有抗性上下限仍适用。出征中不能换装，分房站位/防御/指令仍可预设。

三件不是自动升级：两件号琴＋巡衣保留定心缎带时，本次E生命106/法力57、心理抗性20、法术抗性0；三件生命102/法力59、心理抗性-10、法术10/远程10。丢掉心理保护和生命，换部分法力/感知及其他抗性，取决于职责与敌情。静态装备/套装属性分别列来源，最大资源与相关检定只累计一次。

## 新探索：灯桥巡行

三房30份携带预算，三种可改起点只改战术草稿，不授予新部件、培养或套装：分工清援/低耗追击/后排急拍。

1. 低桥巡弩：两名前排巡卫、后排重箭弩手与左翼微光，按后排/中央实际站位分配保护。
2. 回灯校场：前排援护保护后排医师，右翼群攻中央；法术/心理不会物理接招，但有各自资源与目标代价。
3. 复灯转台：前排守桥长援护左翼医师，后排群攻与中央心理攻击都压中央。法术抗性不抵心理，三件心理代价公开，不隐藏伤害或假定自动省料。

沿原普通结算：3房每房20金币/10XP，通关另60金币/25XP，首通再60金币/25XP；故首180/80、重复120/55，正常通关必得1件。**首通固定号琴，重复三件池独立确定性掉落，不保证缺失部件**。入仓后手动分配，个人所有权规则不变；重复件可留仓，未新增兑换/保底/自动合成，也不修改既有路线掉落。

地图归自由勘探分区。来源入口复用路线绑定方案，遗物寻访册可为指定队员选目标；当前案例将已拥有的旧铜签目标换为E的灯桥路签，取得/分配后才成为个人已持有。所有路线仍可自由选择，不增加等级门槛或任务入场费。

## 实现接点

`expedition-item-sets.mjs`不依赖data/guild，维护一组部件与两档原型效果；输出隔离的计数/效果副本。`equipmentTotals`只汇入一次套装总值，仍返回原护甲/属性/抗性结构，旧装备无变化。不持久化额外的“已激活奖励”，备份恢复后由实际穿戴重新计算，避免重复叠加。

`expedition-item-sets-view.mjs`在装备、保存配装预览、实验编辑、公会实际核对和战报单位检查器显示来源。战报读取**report.config当次装备**，不读当前公会穿戴；旧29战报仍无套装，冻结报告不重算。属性表在有套装时增加独立一列，装备智力-1和套装智力+2分别可见；手机仍为卡片布局。

`expedition-beaconbridge.mjs`及data/adventure/loot/camp接入一条三房路线和三件遗物。新总量27路线/43装备/81普通目标；原技能、培养、费用、奖励公式和资源规则不变。没有必填存档迁移或新的套装配置字段。
