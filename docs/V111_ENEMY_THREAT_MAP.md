# v0.111 敌方攻击范围核对

基线v0.110 `1bdc2394f011d3a54d9a65b5a726963ae5009678`；分支`feature/v111-enemy-threat-map`。继续个人英雄、托管伙伴、自由普通技能及整段自动远征。永久材料经济未实施。

## 玩家现在能完成的操作

以前敌情逐个列出技能，玩家还要自己把目标阵位对照到队员，且容易把单体候选中的所有人理解为都会受击。现在路线总览按草稿映射、公会出征准备按实际装备/训练/已应用职责映射；可按房间查看每条初始普通攻击的来源、类型、目标方式、执行方式、回合窗口、完整候选和单次技能人数上限。

同一范围内两名队友都是单体候选，并非两人都会被同一箭打中；群攻也不会跨位置凑人数。近战按已有固定路线，远攻初始目标空位按既有规则后备，职责目标按当前队员技能核对。每位队友同时列出对应的当前防御、每次防御法力、装备不满足的回退原因、该伤害类型抗性和适用的基础护甲。法术/心理明确护甲不参与；穿甲仍依实际攻击调整。没有总战力、预计伤害或建议最优排序。

“调整某人本房站位与防御”直接定位实际房间与角色。草稿入口只定位，不自动改配置或职责；实际公会入口沿既有流程保留伙伴当前职责指令并转自定义，可撤销。待结算时实际调整按钮禁用。查看和展开不写公会、配置、战报或资产。手机截图验收发现原公会吸顶导航占用多行并遮挡范围卡片，现640px及以下导航随页面滚动，保留全部入口且不横向溢出。

## 必须保留的边界

- 仅按每房公开初始模板与全员存活、无临时效果的站位核对；不调用simulate，不预抽战斗随机数。
- 引用引擎原有选目标规则取得整组候选，再保留原队伍顺序展示；并未抽选下一次实际受击者。单次上限仍是原技能max。
- 普通指令含后备与轮转，不能相加成预计出手次数。窗口展示不是承诺该时点一定施放。
- 破印要求当时存在可破除增益，初始无增益导致空候选不表示安全；预备后会重新选择。未落入其他初始范围也不表示整场不会受击。
- 先攻、减员、援护、召唤、临时效果、实际法力和材料均会改变执行；本图不模拟预备、反应、持续伤害或事件。章节/港口/铸库/邮路另有显著分支提示，不预先决定抵达结果。
- 防御按当前满法力、无临时效果的装备和房间设置展示；真实缺蓝时仍正常回退。
