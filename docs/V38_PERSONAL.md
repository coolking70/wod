# v0.38 个人远征与职责预览

## 交付范围

- 远征复盘顶部增加个人视角：本人实伤、召唤物实伤、有效治疗、增益施加次数、承伤、施法/防御耗蓝、空过、道具使用及本人共享补给消耗。
- 支援关系分为给予和收到，按队员汇总有效治疗与增益；首次治疗、首次增益分别跳回真实记录。多组件增益按施放×对象去重，待生效增益明确包含在应用次数内，不换算为增伤或减伤贡献。
- 法力/耗材/装备条件导致的跳过列出次数与检查方向，不把跳过尝试等同于行动空过。建议不作为胜负因果结论。
- 逐房汇总与代表记录；切换观察角色不改变公会主角；一键回营调整个人和伙伴。
- 回放增加“只看观察角色相关行动”，保留完整行动、涉及其召唤物的行动以及房间/剧情边界。可叠加关键行动精选；定位被过滤的证据时恢复必要的显示范围。
- 伙伴职责改为预览后应用，可按房间查看初始覆盖、敌方候选、每次法力与耗材成本、条件救护和缺装备/缺目标提示。预览不保存、不购买、不消耗资源。高级编辑仍切回自定义。
- 新出征保存主角及职责快照；历史重演采用当时身份，规则仍使用当前引擎。未记录身份的报告只提供观察视角，不虚构历史身份。

## 边界

职责预览采用房间模板与当前站位，不预测途中资源、死亡、召唤或机关导致的遭遇变化。候选对象不保证被选中或命中。实验试跑使用准备页草稿，公会出征使用已应用职责。

本版没有新增职业、伙伴、AI实时决策、美术或旧存档迁移。原有战斗规则和奖励数量未改。
