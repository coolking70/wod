# v149 · 出发前的应急分工核对

v148已实现默认关闭的自动应急，但战前机关说明仍只检查显式拆解指令，玩家直到战后才能知道有哪些应急技能。本轮补齐编辑器与公会出征核对：按实际房间覆盖列出已知/实时等级、标准费用、装备和资格排除，明确区分潜在应急与显式责任。

预览复用v148真实职业目录、课程排除、已配技能排除和费用计算。固定缺装备者不能成为潜在候选；但不根据当前起点MP/库存推断后续房间是否可用，不预测目标、游标、伤亡、成功率或最终最低耗蓝技能。明确等待只提示“实际执行时阻止应急”，不把有窗口或once的等待说成永久禁止。已配置的拆解不再作为应急候选，即使窗口/once使该行未执行，也不会自动重试。

准备页标注实验草稿；公会核对先经原readiness/commandConfig，使用实际已拥有装备、培养与托管职责。预览不变更开关、职责、指令、方案或资产，不授予实验装备。机关说明会分别显示显式拆解队员和有条件的未配拆解应急者，有候选不代表一定清除机关。默认关闭时，原33路线机关说明HTML逐字保持。

只增加只读说明，没有新原版机制、数值、配置字段或存储格式。引擎、技能、敌人、装备、奖励、图片及存储模块逐字保持；[v148原版研究边界](V148_AUTOMATIC_ACTION.md)继续适用，不能把本轮说明当现行Delta规则核实。永久补给仍待用户决定。
