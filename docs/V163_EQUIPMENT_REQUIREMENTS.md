# v0.163 培养与配装条件

成长与装备首次形成明确约束：少量新装备需要真实属性投入，穿上后不能靠退回支撑条件的培养保留效果。购买、换装、整套应用、实验配置及正式出发共用检查；不合格操作在提交前拒绝，不扣金币或经验、不吞物品，也不自动脱装。旧装备没有新门槛。

## 有限规则

定拍长琴：永久魅力19，武器/乐器，魅力+3、意志+1、敏捷−3，诘心回声等级+2、灵感启蒙+1。压潮塔盾：永久体质18，武器/携盾，护甲1、意志+1、敏捷−3，援护架势+2、盾牌格挡+1。沿原商店每件60金币，首次购买后归个人，免费重复换装；不会授予其他职业技能，无新货币或永久消耗。

“永久属性”只用角色基础值＋已支付的永久属性训练。战前倾向+3、物品本身、其他装备/套装与临时增益都不参与，避免自我满足或通过临时改倾向绕开投入。当前每项培养最多+3；即使练满也不可能达到条件的角色，会明确收到上限提示，不诱导无效投入。没有额外的职业锁定。实际E把原灯桥号琴换成新琴时，也会失去原两件套条件；配装预览分别展示，不把新增技能等级当成无代价升级。

在身时，退回一级、全额重修和原子培养草案都检查最终条件。仍满足的其他训练调整照常可行；有必要时先换下装备，再精确退款。新琴和配装册不会删除，退款后不合格的已持有配装仍可保存、导出和恢复，只是不能应用。换装会使旧培养草案快照失效，须重新核对后提交。

实验准备页先拒绝不合格换装/重置，不把非法草稿写入存储。公会装备、属性培养、配装与出发核对显示真实来源及拒绝原因。历史报告按当时的合格培养与配装展示和计算，不使用当前已退款的角色资产；冻结报告仍可完整携带。
