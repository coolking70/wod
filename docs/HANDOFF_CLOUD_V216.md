# v0.216 寻物与队友遗物调配

玩家为一名队员设定寻物目标时，旧面板仍写「个人已持有装备暂不跨人转移」，尽管v139已经允许闲置遗物明确回仓。本轮将这两个既有系统接通：只按真实持有显示队友和当前回仓限制，查看后选中实际持有人、切换到正确部位与已持有筛选，并聚焦该遗物。查看、预览和取消均不改四类业务数据，仍须先解除穿戴及配装册引用，再明确回仓和分配；没有添加直接转移、自动拆装或自动清除配装册。

同时修复实测的回仓预览重绘丢失键盘焦点：进入预览聚焦标题，下一Tab到确认；取消返回原遗物，回仓后定位已有寻物分配入口，明确分配后聚焦目标队员的实际装备。身份和伙伴职责不随临时浏览更换，旧历史、冻结收藏及收益规则保持。跨页旧来源和旧确认继续按原快照检查拒绝，不称跨进程事务锁。
