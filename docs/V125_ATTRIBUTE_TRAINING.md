# v0.125 属性培养

## 核心缺口与规则

v124尝试用经验培养智力时被旧系统拒绝：永久经验只支持职业技能和防御，八项属性只能靠固定角色、战前+3倾向与装备影响。当前补齐与WoD属性/技能分别提升方向相符的核心成长选择，维持个人英雄＋托管伙伴、可切换本人、自由普通技能与独立后期进阶。

八项属性各新增`training['attr:'+key]`，与已有skill:/defense:同一本经验账目。**每级实际+1属性，逐级20/40/60经验，每项最多+3，精确退回该级投入**；没有角色总点数硬上限，不排斥其他属性、技能、课程或进阶。费用和上限沿现有原型，不是已核实原版成本/精通表。

属性投入在出发时加到职业基础属性，再叠战前倾向和装备一次，临时效果另算。没有新行动、额外恢复、补给或奖励：

|属性|沿既有规则的影响|
|---|---|
|力量/灵巧|相关攻击/技能检定；灵巧也参与原自然近战防御|
|体质|每点+4出发生命上限、相关技能检定；不直接改变护甲或抗性|
|敏捷/感知|先攻均值分别每点+2/+1，及相关攻击/防御检定；不增加基础行动次数|
|智力|每点+2出发法力上限、相关施法/救护/防御检定|
|意志|每点+1出发法力上限、相关施法与心智防御|
|魅力|吟游辅助与心理技能中使用魅力的检定|

具体技能按原primary/secondary公式使用属性，不把属性点当技能等级。固定药膳护甲、药敷基础恢复、覆盖人数、行动组件等不因此固定加值。战斗临时属性沿原检定逻辑，不在本阶段动态修改生命/法力上限。召唤、费用、目标、负面效果和资源规则均不改。

## 操作与资产边界

公会成长提供基础/倾向/培养/装备/出发总值及每项具体作用。体质/智力/意志变化同时展示真实出发上限，手机显示为卡片，不要求横向寻找操作。培养/退回沿既有永久事务；技能、防御和属性可在同一草案中精确退款、一次净额应用，累计经验不变。

当前方案的战前倾向仍可自由调整，和付经验的永久培养是两件事。候补按个人战术与实际资产显示；出战者按实际出发配置显示。实验培养仅草稿，可试属性上限但不扣经验、不授予真实培养。公会正式出征会覆盖草稿装备/训练为当前真实值，pending保存实际属性培养；待结算禁止培养/重修，改写个人训练会被资产快照校验拒绝。

培养草案试演保留同一种子、真实装备/职责/课程/进阶和其他队员，只比较该人的当前培养与草案；增加静态属性及生命/法力上限变化提示，完整报告仍可核对。未确认应用前不支付或正式出征，试演不能领奖/收藏正式战报。多页面存档变化仍由现有CAS拒绝覆盖，过期培养快照拒绝应用。

## 实现

- `expedition-attribute-training.mjs`：纯属性加点、来源分解和沿旧公式的出发上限，不导入guild/engine避免循环。
- data只扩展trainingOptions的8个attribute选项；engine buildParty只在基础属性加永久rank一次。没有投入属性的旧报告逐字段及JSON完全一致，不加新报告字段。
- `expedition-attribute-training-view.mjs`与公会成长：属性分解、真实费用、pending禁改；实验培养对attribute单独显示真实属性总值，不误称防御技能等级。
- 既有trainingQuote/plan/ledger/pending/回放/备份沿通用训练map自然接入。试演仅在属性/资源变化时增加描述，旧无属性试演结构不变。

无需新存档迁移/新版本必填字段；无属性投入的公会保持原training。未来旧应用不认识attr键的兼容不承诺。没有新技能、装备、关卡或独立属性货币，仍26路线40装备78普通目标。
