# v0.13 远征总览与策略样本

本版只改准备界面、只读回放总览及样本分析，不改战斗/事件数值，结算与配置格式继续为0.12.0。

## 界面

准备页分成路线总览、事件策略、队伍配置、方案管理。路线总览展示携带物资、当前救援/沉钟策略及条件性的末房分支；它不把计划当成结果。敌情“配置这个房间”与复盘“修改角色”直接打开队伍配置。事件预设直接打开事件策略。方案操作和本机持久化保持原样。

完整战报新增已发生事件链，区分事件记录与未到达，点击可跳转原始记录。明确提示会提前显示尚未播放的结果。

## 固定样本

脚本：node scripts/sample-v13.mjs
数据：dist/samples-v13.json（网页可下载）
共同种子：1–32。封库默认战术；3救援×3沉钟×2构筑，共576次。药师专精同时改药师训练为治疗+3、专修为治疗，其余完全相同。每组保存32份紧凑结果和可重算汇总。

检定分母只包含实际执行的success/failure；unavailable/bypassed/unreached不计入。生命与物资均值包含所有运行，不仅成功者。样本不是当前编辑配置的预测，不代表总体概率。

## 发现

- 18组全部32/32通关。在当前默认补给与敌情下，胜负压力不足以检验大多数构筑取舍。
- 拾取药草固定比赶路多2药草且无代价，两者生命、法力等表现相同。当前赶路没有战术优势，只保留现有选项，不将其包装为平衡分支。
- 默认药师救治成功4/32；专精药师15/32。默认药师均值57、专精69。此专精方案同时变动训练与专修，不能把改善单独归因于某一项。
- 在充足补给的本样本中，救治未改变通关次数或相同构筑/沉钟策略下的平均剩余生命。它主要改变药草向符纸、箭矢转换的收益。
- 沉钟解读27/32成功，破拆29/32成功。默认构筑平均剩余HP：绕过584.8，解读588.3，破拆597.8；破拆耗箭较多。这里不能据此断言破拆普遍最优。

## 验证

98项测试通过，包含样本配置合法性、聚合分母、空样本、18×32覆盖、汇总重算与一条样本对当前引擎复算。原有94项回归通过。

浏览器验证四个准备入口、完整事件链显示与点击定位、药师专精表切换。截图V13_ANALYSIS.jpg。样本读取失败时显示提示，原A/B工具仍可使用。

## 下一步

优先设计可复现的资源紧张挑战和机会成本，而非继续堆叠事件。保留当前基线用于回归，新挑战应让治疗投入、输出构筑与材料支出都可能影响完成目标；先用共同种子验证，再决定是否调整基线。进一步考虑将无代价拾取合并为自动收益，或引入明确而可见的代价。尚无新增CG、后端或自由路线地图。
