# v0.144 · 调压潮炉与蓄能施法

本轮补行动时序取舍：敌人先付费占行动，跨回合维持后才执行原攻击。玩家可以按公开阵位抢攻来源，也可以让屏障对准释放时机；不增加玩家技能、培养/装备或永久补给。参数在结果前冻结，见[V144_PLAN.json](V144_PLAN.json)。

原版官方历史百科[Fertigkeiten](https://www.world-of-dungeons.de/ency/Fertigkeiten)说明预备/普通/先攻等技能时机、费用和类型。它没有证实本轮跨回合蓄能，不能据此宣称当前Delta机制或数字。以下全部新规则、遭遇及数值为项目改编。

蓄能仅供固定公开敌方模板：首次普通行动先核对原技能装备、法力、敌方独立材料及合法目标；成功才付费，记起始回合与最早释放回合。不提前随机选目标或掷攻防。期间每个普通行动用于维持，额外行动不能加速；预备、防御及自然回复仍照常。到期后首次可用普通行动重新选择当时的合法目标，按当前属性、技能等级和攻防结算，不重复扣费；之后执行原普通后备。

来源倒下或房间结束立即取消，已付费用不退；开始失败免费执行原普通后备，不暗中重新蓄能。释放时合法条件丢失则取消，占该次行动。它不是技能增益，净化/破印不移除；途中削蓝不撤销已付费施法，挫志会影响释放时的真实技能等级。没有新增打断技能、眩晕、跨房待发攻击或反应操作。玩家配置不能注入蓄能模板。普通旧路线不产生新字段或随机数消费。新路线/相关新整档需要v144程序，旧143状态可由新程序接续，不保证向旧程序回导新路线。

新单房路线pressurevault，24份携带预算（10草8符6箭）。前排两名140HP/剑术8炉卫，后排240HP术士：首次行动6法力/1敌符纸蓄能潮汐冲击12，起始回合+2后的普通行动冲击中央至多3人；之后微光8攻击前排。公开完整属性、费用、阵位、人数与威胁候选，后备和蓄能不是同时追加攻击。复盘显示当帧蓄能标记，真实开始/维持/释放/取消记录；可核对一次支付并跳回匹配来源。输入文本和数字全部转义，不从外来事件ID猜出处。

正式单人从v143的7920/next72继续，未购买、培养、招募或改已应用职责。72按当前路线默认准备：4回合、六人生还，余9草3符2箭，第三回合实际释放，三名目标均闪避但防御实际共耗8法力；首通原规则100金40XP。73显式把射手破甲重箭/低耗后备和本人吟游诘心指向后排，学者第三回合起护中央：3回合、六人，余9草5符3箭，来源在释放前倒下，重复70金30XP。终档8090/next74，六活跃成员各70XP，候补A整个人物字段不变；仓库、装备、培养、课程、物品、本人/职责、故事及原首证均保留，只新增pressurevault/survive72。正常履历保留71护送、69伤亡与55失败，原五冻结793208字符保持。

八个零经验创始队伍输入（seed1/2/731/732×默认/后排抢攻）全部六人通关；默认释放2/4，抢攻释放2/4，也保留seed2改配后反而释放的反例。当前遭遇仍宽松，单房奖励效率也未做跨路线长期经济校准，不能称策略必需或证明某技能独立贡献；成组改配改变了随机数消耗，不估算避免伤害或推广胜率。完整配置/报告见证据api-final，准确摘要见[V144_PLAYCHECK.json](V144_PLAYCHECK.json)。
