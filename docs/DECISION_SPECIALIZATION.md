# 待决定：是否进入职业专精重构

状态：2026-11-04提出，未获选择、未实现。当前v0.53保留全部基础技能自由搭配，六人出战、战前配置、整段自动结算和共享补给均不改变。

## 为什么现在提出

本轮已连续完成先觉时序、职责改配、节制截疗和缓释照护四个可用增量。验证说明可解释的配合确实发生，但更多辅助不等于候补可替代原队：先觉带来更多受阻但更慢；节制只有在材料尚存时有作用；双药师缓释虽减少普通救护占行动，却因药草竞争在本轮风暴8种子中0/8通关。不能用治疗总量或减低敌人数值将这些结果包装成升级。

继续堆可选技能会扩大每个角色同时承担的职责，未必加深长期角色差异。下一阶段应先决定是否让角色在成长中作出专精承诺，而不是再加几个职责下拉选项。

## 方案A：职业专精分支（推荐，但需要核心方向批准）

在现有成长系统上设计同职业的互斥分支，先只做药师/学者：药师急救与持续护理、学者防护与控场。专精决定可学习的进阶技能集合和资源/行动取舍，同一角色不能同时拥有两个分支的全部能力。维斯和米菈、露弥和奥林可以承担不同长期定位。

保持六人、共享补给、战前策略及全程自动结算。先用设计规格与实验冻结分支的技能范围、学习/重修方式和成长成本，再实现；不承诺候补更强，不自动降低敌人强度。现有职业只允许单一进阶技能的约束会重做，公会成长和战报重演规则将受影响。这是养成结构变化，当前代码没有擅自实现。

## 方案B：保持自由技能，转向有限地城内容

保留当前全部技能自由选择的结构，不引入互斥专精。下一阶段用既有敌方治疗/召唤、阵位、资源和分支机制设计有限新遭遇，让不同队伍在不同任务条件下有用途。现有候补仍是有成本的替换，P2可靠用途按具体关卡验证，不追求所有队伍同等强度。

两者都是有效方向，区别是下一轮投入核心养成结构还是地城内容。无需重新决定已确认的六人自动远征模式，也不涉及账号、多人、商业化、公开发布或额外推送。选择前当前v0.53可完整运行、测试和恢复。
